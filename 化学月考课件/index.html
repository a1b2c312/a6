13分 · 化学变化与物理变化
生活处处是化学，下列过程不涉及化学变化的是（    ） A．米饭变酸　　B．绳锯木断　　C．铁刀生锈　　D．蜡炬成灰
答案B
解析

A 米饭变酸——食物腐败变质，有新物质生成，是化学变化；

B 绳锯木断——只是木料形状、位置发生改变，没有新物质生成，属于物理变化，选 B；

C 铁刀生锈——铁被氧气、水氧化生成铁锈，是化学变化；

D 蜡炬成灰——石蜡燃烧生成 CO2 和 H2O，是化学变化。

判断关键：是否有新物质生成。发光、放热、形状改变都不足以判断化学变化。
23分 · 胶体
关于胶体的下列说法正确的是（    ） A．溶液、胶体、浊液均属于化合物 B．胶体区别于其他分散系的本质特征是丁达尔效应 C．实验室向沸水中滴加 FeCl3 饱和溶液至液体呈红褐色制备 Fe(OH)3 胶体 D．用激光分别照射 CuSO4 溶液和 Fe(OH)3 胶体时，均可以看见一条光亮的通路
答案C
解析

A 三种分散系都是混合物，不是化合物；

B 本质特征是分散质粒子直径在 1～100 nm 之间，丁达尔效应只是区分溶液和胶体的方法；

C ✔ 向沸水中滴加饱和 FeCl3 溶液、继续煮沸至红褐色，即得 Fe(OH)3 胶体，操作正确；

D 溶液没有丁达尔效应，只有 Fe(OH)3 胶体中能看到光亮通路。

Fe(OH)3 胶体制备口诀："沸水、滴加、红褐停"，不能搅拌、不能久沸。
33分 · 物质分类与电解质
下列关于纯净物、混合物、电解质、非电解质的正确组合为（    ）
纯净物混合物电解质非电解质
A盐酸澄清石灰水硫酸干冰
B冰水混合物酒精溶液碳酸钙氯气
C氨水Fe(OH)3 胶体铜硫酸钡
D胆矾食盐水氯化铜氨气
答案D
解析

D ✔ 胆矾 CuSO4·5H2O 是纯净物（结晶水合物）；食盐水是混合物；CuCl2 是电解质；NH3 自身不能电离，是非电解质。

A 盐酸是 HCl 的水溶液，属于混合物，不是纯净物；

B 氯气是单质——单质既不是电解质也不是非电解质；

C 氨水是混合物；铜是单质不是电解质；BaSO4 虽难溶，但熔融状态能导电，是电解质。

易错点：①结晶水合物是纯净物；②单质和混合物既不是电解质也不是非电解质；③"难溶≠非电解质"，BaSO4、CaCO3 都是电解质。
43分 · 离子共存
下列各组中的离子，能在溶液中大量共存的是（    ） A．H+、Ag+、Na+、NO3− B．K+、Ca2+、Cl−、CO32− C．Ca2+、Cl−、OH−、NO3− D．Na+、Cu2+、SO42−、OH−
答案A
解析

A ✔ 四种离子之间不发生反应，可以大量共存；

B Ca2+ + CO32− = CaCO3↓，生成沉淀，不能共存；

C Ca2+ 与 OH− 生成微溶物 Ca(OH)2，不能大量共存；

D Cu2+ + 2OH− = Cu(OH)2↓，生成蓝色沉淀，不能共存。

共存口诀：一查沉淀（溶度积）、二查气体、三查弱电解质（水、弱碱、弱酸）。
53分 · 离子方程式正误判断
下列化学方程式或离子方程式中，正确的是（    ） A．铜与硝酸银溶液反应：Cu + Ag+ = Cu2+ + Ag B．少量 SO2 与 NaOH 溶液的反应：SO2 + 2OH− = SO32− + H2O C．石灰乳与盐酸反应：H+ + OH− = H2O D．稀硝酸与铜片的反应：Cu + 4HNO3(稀) = Cu(NO3)2 + 2NO2↑ + 2H2O
答案B
解析

A 电荷不守恒，应为 Cu + 2Ag+ = Cu2+ + 2Ag；

B ✔ SO2 少量、NaOH 过量，产物为正盐 SO32−，方程式正确；

C 石灰乳是浊液，Ca(OH)2 应写化学式，应为 Ca(OH)2 + 2H+ = Ca2+ + 2H2O；

D 稀硝酸的还原产物是 NO 而不是 NO2，应为 Cu + 4HNO3(稀) = Cu(NO3)2 + 2NO↑ + 2H2O。

查离子方程式四步：拆对了吗 → 守恒吗（电荷、质量）→ 产物对吗 → 与"量"匹配吗。
63分 · Fe(OH)₃胶体制备与性质
某同学在实验室完成了 Fe(OH)3 胶体的制备与性质实验后有以下实验记录，其中恰当的是（    ） A．将饱和 FeCl3 溶液滴加到 NaOH 溶液中可制得 Fe(OH)3 胶体 B．Fe(OH)3 胶体带正电，FeCl3 溶液呈电中性 C．向 Fe(OH)3 胶体中滴加稀盐酸，先有红褐色沉淀生成，后沉淀消失 D．用滤纸过滤 Fe(OH)3 胶体，滤纸上得到红褐色沉淀
答案C
解析

A 滴入 NaOH 溶液直接生成 Fe(OH)3沉淀；制胶体必须滴入沸水中；

B 胶体整体呈电中性，是"胶体粒子带正电荷"，表述偷换概念；

C ✔ 电解质溶液使胶体聚沉生成红褐色沉淀；盐酸过量后 Fe(OH)3 与酸反应溶解，变为 FeCl3 溶液，"先聚沉后溶解"正确；

D 胶体粒子能透过滤纸，过滤得不到沉淀（半透膜才能渗析）。

对比：胶粒能透过滤纸、不能透过半透膜；加入电解质、加热、搅拌都可聚沉。
73分 · 混盐与复盐
"混盐"是指一种金属离子与多种酸根阴离子构成的盐，如氯化硝酸钙 [Ca(NO3)Cl]。"复盐"是指多种简单阳离子和一种酸根阴离子构成的盐，如 KAl(SO4)2。下列化合物中属于"复盐"的是（    ） A．CaOCl2　　B．Cu2(OH)2CO3　　C．Ca(ClO)Cl　　D．(NH4)2Fe(SO4)2
答案D
解析

D ✔ (NH4)2Fe(SO4)2（硫酸亚铁铵）含有 NH4+、Fe2+ 两种阳离子和一种酸根 SO42−，是典型的复盐（莫尔盐）；

A CaOCl2 含 Cl− 与 ClO− 两种酸根，属混盐（与 C 本质相同）；

B Cu2(OH)2CO3（碱式碳酸铜）含 OH− 和 CO32−，属于碱式盐；

C Ca(ClO)Cl 是一种阳离子对两种酸根，属混盐。

抓定义关键词：复盐 = "多种阳离子 + 一种酸根"；混盐 = "一种阳离子 + 多种酸根"。
83分 · 元素转化关系推断
A、B、C、D、E 中都含有同一种元素，它们之间的相互转化关系如图所示（A —H₂O→ B；A —硝酸→ C；B —盐酸→ D；C、D —Na₂CO₃/AgNO₃溶液→ E；E —高温→ A；E 为中心），其中所含的相同元素是（    ） A．碳　　B．铜　　C．钙　　D．铁
答案C（元素：钙）
解析

突破口：E 高温分解生成 A，A 与水化合生成 B——联想 CaCO3 高温分解 → CaO → Ca(OH)2。

A = CaO，B = Ca(OH)2，D = CaCl2（B 与盐酸反应），C = Ca(NO3)2（D 与 AgNO3 溶液反应），E = CaCO3（A、B、D 与 Na2CO3 反应均可生成）。

A(CaO) + H2O → B[Ca(OH)2]；　B + 2HCl → D(CaCl2) + 2H2O

E(CaCO3) 高温 → A(CaO) + CO2↑；　C、D + Na2CO3 → E↓

五种物质都含钙元素，故选 C。

"高温分解 + 与水化合放热"是钙三角（CaCO3–CaO–Ca(OH)2）的标志性特征。
93分 · 电子转移方向与数目
下列氧化还原反应中，电子转移的方向和数目均正确的是（    ） A．10KI + 2KMnO4 + 8H2SO4 = 5I2 + 6K2SO4 + 2MnSO4 + 8H2O（Mn→I₂ 得 2×5e⁻，I 失 10×e⁻） B．Cu + 2H2SO4(浓) =(Δ)= CuSO4 + SO2↑ + 2H2O（2e⁻ 标注于 Cu 与 H₂SO₄ 之间） C．2CO + O2 =(点燃)= 2CO2（失去 2e⁻ / 得到 2e⁻） D．2Na + 2H2O = 2NaOH + H2↑（e⁻）
答案A
解析

A ✔ 10 个 I−（−1→0）共失去 10×e−；2 个 Mn（+7→+2）共得到 2×5e−，得失电子相等，方向、数目均正确；

B 2H2SO4 中只有 1 个 S 被还原（+6→+4），电子转移应标在 Cu 与被还原的 S（→SO2）之间，图中指向错误；

C 2 个 C（0→+4）应"失去 2×2e−"，标 2e⁻ 数目不对；

D 2 个 Na（0→+1）共失 2e⁻，应标"2×e−"，只标 e⁻ 数目不对。

双线桥口诀："桥连同种元素，得失分开标，数目乘系数"。每条线两端必须是同一种元素的价态。
103分 · 气体制备装置选择
实验室用 FeS 固体和稀硫酸反应制取 H2S 气体，反应的方程式为：FeS + H2SO4 = FeSO4 + H2S↑。H2S 是一种有毒气体，密度大于空气，可溶于水形成酸性溶液，下列说法合理的是（    ） A．可用过氧化氢制氧气的发生装置制取 H2S 气体 B．收集 H2S 气体可用排水法 C．可用向下排空气法收集 H2S 气体 D．可用 NaCl 溶液吸收 H2S 气体，防止污染空气
答案A
解析

A ✔ "固 + 液 → 气、不加热"，与 H2O2 分解制 O2 的发生装置同型（固液不加热型）；

B H2S 可溶于水，不能用排水法收集；

C H2S 密度大于空气，应用向上排空气法；

D NaCl 溶液不与 H2S 反应，不能吸收；应选用 CuSO4 溶液或 NaOH 溶液进行尾气处理。

气体制备三步曲：发生装置看"状态+条件"，收集看"密度+溶解性"，尾气看"毒性+酸碱性"。
113分 · 黑火药反应分析
火药是我国古代四大发明之一，引爆时发生 S + 2KNO3 + 3C = K2S + N2↑ + 3X 反应，下列说法正确的是（    ） A．X 是空气的成分之一，有毒性 B．该反应是氧化还原反应，发生化合价变化的有两种元素 C．S 得电子，发生的是氧化反应 D．每生成 1 个 N2 分子转移 12 个电子
答案D
解析

由原子守恒，X 为 CO2。化合价变化：S：0→−2；N：+5→0；C：0→+4。

A CO2 是空气成分，但无毒；

B 化合价变化的元素有 S、N、C 三种；

C S 得电子、化合价降低，被还原，发生还原反应；

D ✔ 3 个 C 共失去 3×4 = 12e⁻（N 得 10e⁻ + S 得 2e⁻ = 12e⁻），即每生成 1 个 N2 转移 12 个电子。

电子守恒是"算转移电子数"最快的路径：失电子总数 = 得电子总数 = 转移电子数。
123分 · 氧化剂与还原剂之比
某温度下，将氯气通入 NaOH 溶液中，反应得到 NaCl、NaClO、NaClO3 的混合液，经测定 ClO− 与 ClO3− 的物质的量之比为 1:1，则氯气与 NaOH 溶液反应时氧化剂与还原剂的物质的量之比为（    ） A．21:5　　B．13:3　　C．3:1　　D．3:13
答案C
解析

歧化反应中氧化剂、还原剂都是 Cl2。设 n(ClO−) = n(ClO3−) = n mol：

· 被氧化：Cl（0→+1）失 1e⁻，Cl（0→+5）失 5e⁻，共失 6n e⁻，被氧化的 Cl 为 2n mol（作还原剂）；

· 被还原：Cl（0→−1）每个得 1e⁻，需 6n mol Cl（作氧化剂）；

· 氧化剂 : 还原剂 = 6n : 2n = 3 : 1，选 C。

同一元素的歧化反应，直接用电子守恒列式最快，不必写完整方程式。
133分 · 工艺流程与氧化还原
KMnO4 是常见的氧化剂，实验室以 MnO2 等为原料制取少量 KMnO4：MnO2 —（KClO₃、KOH，熔融）→ K₂MnO4 —（水，溶解）→ —（通 CO₂，K₂MnO₄歧化）→ 过滤（得 MnO₂ 循环）→ 结晶 → KMnO₄粗品。下列说法不正确的是（    ） A．"熔融"过程中氧化剂是 KClO3，还原剂是 MnO2 B．"溶解"后的溶液中存在大量的 K+、Cl−、MnO4− C．流程中 MnO2 可以循环使用 D．"K2MnO4 歧化"时氧化剂与还原剂的物质的分子个数比为 1:2
答案B
解析

熔融反应：3MnO2 + KClO3 + 6KOH (熔融) = 3K2MnO4 + KCl + 3H2O

A ✔ KClO3 中 Cl：+5→−1 被还原，作氧化剂；MnO2 中 Mn：+4→+6 被氧化，作还原剂；

B ✘ "K2MnO4"中锰酸根是 MnO42−（绿色），不是 MnO4−（紫色高锰酸根），B 错误，选 B；

C ✔ 歧化生成的 MnO2 过滤后可返回"熔融"步骤循环使用；

D ✔ 歧化反应 3K2MnO4 + 2CO2 = 2KMnO4 + MnO2↓ + 2K2CO3 中，作氧化剂（→MnO2）与作还原剂（→MnO4−）的 K2MnO4 个数比为 1 : 2。

MnO42−（锰酸根，绿）与 MnO4−（高锰酸根，紫）一字之差、价态不同，是最经典的设错点。
143分 · 标准电极电势信息题
化学常用标准电极电势 Eθ（氧化型/还原型）比较物质氧化能力：Eθ 值越高，氧化型物质的氧化能力越强；Eθ 值越低，还原型物质的还原能力越强。 数据（酸性条件）：PbO₂/PbSO₄ 1.685 V，MnO₄⁻/Mn²⁺ 1.51 V，Fe³⁺/Fe²⁺ 0.77 V，Cl₂/Cl⁻ 1.36 V，Co³⁺/Co²⁺ 1.92 V。下列说法错误的是（    ） A．酸性条件下氧化性强弱顺序为 Co³⁺ > PbO₂ > Cl₂ > Fe³⁺ B．PbO2 与浓盐酸反应可以制备 Cl2 C．酸性环境下 Cl− 的还原性比 Co2+ 强 D．硫酸酸化的足量 KMnO4 溶液与 FeCl2 溶液反应的离子方程式为 MnO4− + 5Fe2+ + 8H+ = 5Fe3+ + Mn2+ + 4H2O
答案D
解析

A ✔ 按 Eθ 排序：Co³⁺(1.92) > PbO₂(1.685) > Cl₂(1.36) > Fe³⁺(0.77)，正确；

B ✔ Eθ(PbO₂/PbSO₄) = 1.685 V > Eθ(Cl₂/Cl⁻) = 1.36 V，PbO₂ 能把 Cl⁻ 氧化成 Cl₂；

C ✔ Eθ 越低还原型还原能力越强：Cl⁻（1.36）> Co²⁺（1.92），正确；

D ✘ FeCl2 电离出的 Cl⁻ 也具有还原性，Eθ(MnO₄⁻/Mn²⁺) = 1.51 V > 1.36 V，足量酸性 KMnO₄ 会把 Cl⁻ 一并氧化，该离子方程式漏掉了 Cl⁻ 被氧化，错误。实验中应改用 FeSO₄ 等不含 Cl⁻ 的亚铁盐。

信息题要"用足信息"：比较氧化性/还原性时，别忘了共存的还原性离子（Cl⁻）会"抢"氧化剂。

15物质的分类 · 电解质 · 离子方程式
准确掌握化学基本概念和研究方法是学好化学的重要手段。 (1) 有以下物质：①熔融氯化钠　②铝　③乙醇　④氨水　⑤氯化氢气体　⑥NaHSO4 固体　⑦Al(OH)3 固体 　ⅰ．其中能导电的是____；属于电解质的是____；属于非电解质的是____。 　ⅱ．写出物质①、⑥溶于水时的电离方程式：____、____。 (2) 关于酸、碱、盐的下列各种说法中，正确的是____（填字母）。 　A．化合物电离时，生成的阳离子有氢离子的是酸 　B．化合物电离时，生成的阴离子有氢氧根离子的是碱 　C．化合物电离时，生成金属阳离子(或铵根离子)和酸根阴离子的是盐 　D．酸溶液一定显酸性，碱溶液一定显碱性，盐溶液一定显中性 (3) 写出⑦作为抗酸药和胃酸反应的离子方程式____；④和⑤反应的离子方程式____；NaHCO3 和⑥反应的离子方程式____。
15题答案 (1)ⅰ 能导电 ①②④；电解质 ①⑤⑥⑦；非电解质 ③ 　(2) C

(1)ⅱ 电离方程式：

① NaCl（熔融）= Na+ + Cl− ⑥ NaHSO4 = Na+ + H+ + SO42−（水溶液中完全电离）

逐项分析：①熔融 NaCl 有自由移动的离子，能导电，是电解质；②铝是金属单质，能导电，但单质既不是电解质也不是非电解质；③乙醇不电离、不导电，是非电解质；④氨水是混合物（含 NH3·H2O），能导电，但混合物不是电解质；⑤HCl 气体溶于水自身完全电离，是电解质；⑥NaHSO4 是盐，电解质；⑦Al(OH)3 难溶但溶解的部分完全电离，是电解质（弱碱）。

(2) 解析：

A、B 错在"有"字——必须是电离出的阳离子全部是 H⁺ 的才是酸（如 NaHSO4 电离出 H⁺ 但是盐）、阴离子全部是 OH⁻ 的才是碱；

C ✔ 符合盐的定义；D 盐溶液不一定中性，如 Na2CO3 溶液显碱性。

(3) 离子方程式：

Al(OH)3 + 3H+ = Al3+ + 3H2O NH3·H2O + H+ = NH4+ + H2O（一水合氨是弱碱，写化学式） HCO3− + H+ = CO2↑ + H2O
易错提醒：能导电 ≠ 电解质（还要看是不是化合物、是否自身电离）；NH3·H2O、Al(OH)3 等弱电解质在离子方程式中写化学式。
16分类观 · 三酸两碱 · 导电能力曲线
Ⅰ．化工生产常用到"三酸两碱"："三酸"指硝酸、硫酸和盐酸，"两碱"指烧碱（NaOH）和纯碱（Na2CO3）。 (1) 从物质的分类角度看，类别归属不恰当的一种物质是（填化学式）____。 (2) "三酸"与"两碱"之间均可反应，酸过量时若用化学方程式表示有六个，若用离子方程式表示却只有两个，请写出这两个离子方程式____、____。 Ⅱ．现有以下物质：①SiO2　②NaOH　③Ba(OH)2　④NaHSO4。 (3) 已知①可以溶于②的水溶液中，发生反应：2NaOH + SiO2 = Na2SiO3 + H2O，反应过程中溶液的导电能力可近似地用图中的____（填字母）曲线表示（生成水对溶液体积的影响忽略不计）。 (4) 利用图甲装置探究③与④在水溶液中的反应：从滴定管中逐滴将④（NaHSO4）溶液加入到③（Ba(OH)2）溶液中，浑浊度变化如图乙。已知：a 点浑浊度最大，视为 a 点时 Ba2+ 与 SO42− 恰好完全沉淀，o→a 的过程中，发生反应的离子方程式为____；b 点溶液呈中性，a 点到 b 点过程中，发生反应的化学方程式为____。
16题答案 (1) Na2CO3 　(3) b

(1) 解析：

纯碱 Na2CO3 从分类上属于盐（因其水溶液显碱性而得名"纯碱"），把它归为"碱"不恰当。

(2) 两个离子方程式：

强酸 + NaOH：H+ + OH− = H2O 强酸 + Na2CO3（酸过量）：2H+ + CO32− = CO2↑ + H2O

盐酸、硫酸、硝酸都是强酸（H+），NaOH 是强碱（OH−），酸过量时碳酸根全部转化为 CO2，所以 6 个化学方程式对应 2 个离子方程式。

(3) 解析：

NaOH 是强电解质，随 SiO2 加入，OH− 不断被消耗，离子浓度减小，导电能力逐渐下降；NaOH 反应完后，过量 SiO2 不溶也不导电，溶液成分为较低浓度的 Na2SiO3，离子浓度基本不变，导电能力保持较低水平——对应曲线 b（先降后平）。

(4) 答案：

o→a（1:1 恰好沉淀）：Ba2+ + H+ + OH− + SO42− = BaSO4↓ + H2O a→b（NaOH 被继续中和）：NaOH + NaHSO4 = Na2SO4 + H2O

思路：a 点时 n(NaHSO4) : n(Ba(OH)2) = 1 : 1，Ba²⁺、SO₄²⁻ 恰好全部沉淀，此时溶液中剩余 1 份 OH⁻（即 NaOH）；继续滴加 NaHSO4 至 b 点，H⁺ 恰好中和剩余 OH⁻，溶液呈中性。a→b 段没有新沉淀生成，浑浊度基本不变。

"量"对离子方程式的影响：Ba(OH)₂ 与 NaHSO₄ 按 1:1 与 1:2 混合，离子方程式写法完全不同，是高考高频考点。
17胶体 · Fe(OH)₃制备与安全标识
由工业明胶制成的胶囊往往含有超标的重金属铬，会对人体造成伤害。明胶是水溶性蛋白质混合物，溶于水形成胶体。 (1) 已知 Fe(CrO2)2 中铬元素是 +3 价，则其中铁元素是____价，CrO2− 是一种酸根离子，则 Fe(CrO2)2 属于____（填"酸""碱""盐"或"氧化物"）。 (2) 鉴别明胶的水溶液和 K2SO4 溶液的简单方法是____。 (3) 实验室进行 Fe(OH)3 胶体的制备实验并检验其性质。 　① 若将 5~6 滴饱和 FeCl3 溶液分别滴入下列物质中，继续煮沸至液体呈红褐色，停止加热，能形成胶体的是____。 　　A．冷水　　B．沸水　　C．NaOH 浓溶液　　D．NaCl 浓溶液 　② 实验室常见安全标识：①护目镜　②排风　③热烫　④明火　⑤洗手　⑥锐器。为了实验安全，制备氢氧化铁胶体的实验，应该标注的图标除①⑤外，还应标注的图标有____。 　③ 制备 Fe(OH)3 胶体的化学方程式是____；若向 Fe(OH)3 胶体中逐滴滴入过量稀硫酸，先产生红褐色的 Fe(OH)3 沉淀，然后沉淀____（填实验现象），变为棕黄色溶液。
17题答案 (1) +2（1分）、盐（1分） 　(3)① B（1分）　② ②③④　③末空 逐渐溶解（沉淀溶解）（1分）

(1) 解析：

CrO2− 中 O 为 −2 价，则 Cr 为 +3 价；设 Fe 为 x 价：x + 2×(+3) + 4×(−2) = 0，解得 x = +2。Fe(CrO2)2 由金属阳离子 Fe2+ 与酸根 CrO2− 构成，属于盐（亚铬酸亚铁）。

(2) 答案：

用一束光分别照射两种液体，从侧面能看到一条光亮"通路"的是明胶水溶液（胶体，丁达尔效应），无此现象的是 K2SO4 溶液。

(3) 解析：

① 制备 Fe(OH)3 胶体必须把饱和 FeCl3 溶液滴入沸水中，选 B。冷水不水解；NaOH 浓溶液生成沉淀；NaCl 浓溶液不能促进水解。

② 实验涉及加热至沸腾（③热烫）、酒精灯（④明火）、需通风（②排风），故还应标注 ②③④。

③ FeCl3 + 3H2O (Δ) = Fe(OH)3(胶体) + 3HCl

滴入过量稀硫酸：电解质使胶体聚沉生成红褐色沉淀；酸过量后发生中和反应，沉淀逐渐溶解，生成棕黄色 Fe2(SO4)3 溶液（Fe3+ 呈棕黄色）。

书写该化学方程式必须注明"（胶体）"，用"="号不用"⇌"，条件写 Δ——这是阅卷高频扣分点。
18氧化还原反应综合
(1) 下列粒子中，只有还原性的是____（填序号）：①S2−　②Fe2+　③Fe3+　④S　⑤H+　⑥Na+　⑦Mg (2) 吸入人体内的氧有 2% 转化为氧化性极强的"活性氧"，它能加速人体衰老，被称为"生命杀手"。服用含硒元素(Se)的化合物亚硒酸钠（Na2SeO3），能消除人体内的活性氧，由此推断 Na2SeO3 在反应中作____（填氧化剂或还原剂）。 (3) 在 Fe + 4HNO3(稀) = Fe(NO3)3 + NO↑ + 2H2O 的反应中： 　① HNO3 表现了____性和____性。　② 上述反应的离子方程式为____。 (4) 氯化铵溶液可除去铜器表面的氧化铜：4CuO + 2NH4Cl =(Δ)= 3Cu + CuCl2 + N2↑ + 4H2O。 　① 用双线桥标出上述反应中电子转移的方向和数目。　② 氧化剂和还原剂个数之比是____。 (5) MnO2 + 4HCl(浓) =(Δ)= MnCl2 + Cl2↑ + 2H2O 该反应中氧化剂是____，氧化产物是____；用单线桥标出上述反应中电子转移的方向和数目。
18题答案 (1) ①⑦ 　(2) 还原剂 　(3) 氧化性、酸性（各1分） 　(4)② 3:2 　(5) 氧化剂 MnO2，氧化产物 Cl2

(1) 解析：

最低价态只有还原性：①S2−（S 的最低价 −2）、⑦Mg（0 价金属单质）只有还原性，填 ①⑦。中间价态既有氧化性又有还原性（②Fe2+、④S）；最高价态只有氧化性（③Fe3+、⑤H+、⑥Na+）。

(2) 解析：

"活性氧"氧化性强，Na2SeO3 把它消除（被还原），说明 Na2SeO3 失电子，作还原剂（Se：+4→+6）。

(3) 答案与解析：

① HNO3 中部分 N（+5→+2）被还原，表现氧化性；部分 N 化合价不变、生成 Fe(NO3)3，表现酸性（4 份 HNO3：1 份作氧化剂、3 份起酸的作用）。

② Fe + 4H+ + NO3− = Fe3+ + NO↑ + 2H2O

(4) 答案与解析：

① 双线桥（箭头由变价元素指向变价元素，数目 = 变价原子数 × 每个转移电子数）：

失 2×3e−：N：−3 → 0（2NH4Cl 中的 N 被氧化）
得 3×2e−：Cu：+2 → 0（4CuO 中的 3 个 Cu 被还原）

② 被还原的 CuO（氧化剂）为 3 份，作还原剂的 NH4Cl 为 2 份，氧化剂 : 还原剂 = 3 : 2（注意：4 个 CuO 中有 1 个 Cu 转入 CuCl2 未变价，不计入氧化剂）。

(5) 答案与解析：

氧化剂是 MnO2（Mn：+4→+2），氧化产物是 Cl2（Cl：−1→0，被氧化）。

单线桥：2e−，由 Cl（−1，4HCl 中的 2 个 Cl⁻）→ Mn（+4）；即 MnO2 + 4HCl(浓) =(Δ)= MnCl2 + Cl2↑ + 2H2O，桥上标"2e−"，箭头从被氧化的 Cl⁻ 指向 MnO₂。

注意：4HCl 中只有 2 个 Cl⁻ 被氧化，另外 2 个 Cl⁻ 进入 MnCl2 起酸性作用——所以单线桥标 2e−，不是 4e⁻。

"部分参与氧化还原"是最大陷阱：先数清有几个原子变价，再乘每个转移的电子数；单线桥只标电子数、不写"得失"。
