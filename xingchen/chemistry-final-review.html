第 1 课时

物质的分类 · 离子反应 · 胶体

课时目标　建立「分类观」与「微粒观」：会用树状/交叉分类法判断物质类别，能区分电解质与导电性，能按「拆、删、查」三步书写与判断离子方程式，掌握胶体的本质特征与制备方法。
本节聚焦　易错集中点：电解质≠能导电；Fe(OH)₃ 胶体制备不能用 NaOH；离子方程式漏写参与反应的离子；少量/过量对产物的影响。
共 7 题 · 难度系数 0.39~0.70
01难度 适中 0.65单选题海南 · 26-27高一上—海南—期中
8. 某样品可能含有下列物质中的一种或几种：、、、、。对该样品进行初步测试后，得出如图所示的结果。

下列关于该样品组成的分析正确的是
A．一定是的纯净物
B．可能是，的混合物
C．可能是、的混合物
D．可能是、的混合物
参考答案
B
解析
样品为白色固体且加水后全部溶解：CuSO₄·5H₂O 为蓝色且溶液呈蓝色、AgCl 与 BaCO₃ 均难溶于水，三者一定不含。滴加酚酞变红说明溶液呈碱性，NaOH 一定含有。NaCl 白色易溶、溶液中性，含与不含都不影响上述三个现象，因此只能确定「NaOH 一定含有，NaCl 可能含有」。故样品可能是 NaOH 与 NaCl 的混合物。
易错点
① 把「酚酞变红」直接等同于「只有 NaOH」，忽略 NaCl 可以共存；② 忘记 CuSO₄·5H₂O 本身是蓝色晶体，第一步「观察外观」就已排除；③ 把「可能是」误当成「一定是」。
讲评要点
讲评时按流程三步走：先看颜色（排除有色物质）→ 再看溶解性（排除难溶物）→ 最后看酸碱性（锁定碱性物质），每一步都问「还剩谁、谁一定在、谁可能在」。这类题的答案往往是「一定含 A，可能含 B」，而不是纯净物。
02难度 困难解答题河南 · 河南省南阳市2026-2027学年高一上学期
15. 分类是学习化学的一种重要方法，科学合理的分类对于系统掌握知识、提高学习效率、解决问题都有着重要的意义。回答下列问题：
(1)现有下列物质：①石墨 ②酒精 ③稀硫酸 ④ ⑤溶液 ⑥液态HCl ⑦固体 ⑧溶液
Ⅰ．上述状态的物质能导电的是__________(填序号，下同)，属于电解质的是__________。
Ⅱ．常温常压下，等质量的、HCl体积之比__________。
Ⅲ．1 L 溶液中含 54 g，从该溶液中取出20 mL，并稀释到100 mL，稀释后溶液中硫酸根离子的物质的量浓度为__________mol·L-1。
Ⅳ．⑤与少量⑦的水溶液混合，发生反应的离子方程式为______________________。
(2)如图为氯及其化合物的“价—类”二维图。缺失的类别b为__________，将物质a通入石灰乳可制得，写出相应反应的化学方程式__________________________________。

参考答案
见要点
解析
Ⅰ 能导电看「当前状态有无自由移动的离子或电子」：石墨（自由电子）、稀硫酸/溶液（自由离子）、熔融盐可导电；固态离子化合物、液态 HCl（未电离）、酒精、蔗糖不导电。电解质必须是「化合物」，且指在水溶液或熔融状态下能导电的性质，与当前是否导电无关——石墨是单质、稀硫酸是混合物，都不是电解质。Ⅱ 等质量气体体积比等于物质的量之比，即摩尔质量的反比。Ⅲ 先由 54 g 溶质求原溶液浓度，取出 20 mL 时浓度不变，再按稀释前后溶质物质的量守恒 c₁V₁=c₂V₂ 计算。
易错点
最典型错误是把「能导电」与「是电解质」混为一谈：金属单质、石墨能导电但不是电解质；NaCl 固体是电解质但固态不导电。另一个坑是稀释时把「取出 20 mL」当成浓度被稀释 5 倍。
讲评要点
用一张两栏表把「物质 / 能否导电 / 是否电解质 / 理由」逐行填完，让学生自己发现两列并不一致。强调电解质的判断对象是化合物、判断依据是「水溶液或熔融态能否导电」。

A．       B．       C．
参考答案
见要点
解析
Ⅰ 盐 = 金属阳离子（或 NH₄⁺）与酸根阴离子构成的化合物；电解质须为化合物，排除单质与混合物；能导电看当前状态。电离方程式注意原子团不能拆（如 KClO₃ = K⁺ + ClO₃⁻）。Ⅱ 分散系分类的唯一依据是分散质粒子直径（<1 nm 溶液、1~100 nm 胶体、>100 nm 浊液）；胶粒能透过滤纸但不能透过半透膜。实验室制 Fe(OH)₃ 胶体是把饱和 FeCl₃ 溶液滴入沸水并加热至红褐色，方程式为 FeCl₃ + 3H₂O = Fe(OH)₃(胶体) + 3HCl，不能写沉淀符号，也不能用 NaOH。

04难度 较难 0.4单选题辽宁 · 26-27高一上—辽宁沈阳—期中
8. 下列实验操作正确且能达到实验目的的是

A．用NaOH溶液除去Cl2尾气，防止污染环境B．证明过氧化钠和水的反应是放热反应

C．制备氢氧化铁胶体D．用焰色试验检验溶液中的Na+
A．AB．BC．CD．D
参考答案
B
解析
A：Cl₂ 通入 NaOH 溶液的导管没有伸入液面以下，气体无法与吸收液接触，不能除尾气。B：向包有 Na₂O₂ 的脱脂棉滴 2 滴水，棉花燃烧，说明反应放热使温度达到着火点，同时生成 O₂ 助燃，能达到目的。C：把饱和 FeCl₃ 滴入 NaOH 溶液并加热，得到的是 Fe(OH)₃ 沉淀而不是胶体；制备胶体必须滴入沸水。D：焰色试验要用铂丝或光洁无锈的铁丝，玻璃棒本身含钠且不能耐高温灼烧，操作错误。
易错点
学生常只记「NaOH 能吸收 Cl₂」「FeCl₃ 能制胶体」而忽略装置细节，忘了看导管长短、滴加对象和仪器材质。
讲评要点
提醒一句口诀：「先看装置能不能通气，再看试剂能不能反应」。实验操作题的正误往往藏在导管、仪器和滴加顺序里，而不在化学原理上。
05难度 适中 0.65单选题海南 · 26-27高一上—海南—期中
10. 氢氧化钡可用于制特种肥皂、杀虫剂，也可用于硬水软化等。下列有关反应的离子方程式正确的是
A．向氢氧化钡溶液中通入少量二氧化碳：
B．向氢氧化钡溶液中加入硫酸镁溶液：
C．向氢氧化钡溶液中加入稀硫酸：
D．向氢氧化钡溶液中加入少量碳酸氢钾：
参考答案
C
解析
A：向 Ba(OH)₂ 中通入少量 CO₂，应生成 BaCO₃ 沉淀，正确式子为 Ba²⁺ + 2OH⁻ + CO₂ = BaCO₃↓ + H₂O，选项写成了 CO₂ 与 OH⁻ 生成 HCO₃⁻（那是 CO₂ 过量的情形）。B：Ba(OH)₂ 与 MgSO₄ 反应时 Mg²⁺ 与 OH⁻ 也会生成 Mg(OH)₂ 沉淀，选项只写 BaSO₄，漏了另一半。C：Ba(OH)₂ 与稀硫酸反应，H⁺ 与 OH⁻、Ba²⁺ 与 SO₄²⁻ 两组离子同时反应，配比 2:2:1:1，式子正确。D：加入少量 KHCO₃ 时 HCO₃⁻ 只与 1 个 OH⁻ 反应生成 CO₃²⁻ 并立即与 Ba²⁺ 沉淀，正确式子为 Ba²⁺ + OH⁻ + HCO₃⁻ = BaCO₃↓ + H₂O，选项系数与产物均错。
易错点
「少量 / 过量」是离子方程式的第一大坑；另一个是「漏写同时发生的另一组离子反应」（Ba²⁺ + SO₄²⁻ 与 Mg²⁺ + OH⁻ 常常只写一半）。
讲评要点
教一个固定动作：先列出溶液中所有离子，再两两配对找「能生成沉淀/气体/弱电解质」的组合，一组都不能漏；最后用「少量者系数为 1」定系数、查电荷与原子守恒。
06难度 较难 0.39单选题辽宁 · 26-27高一上—辽宁沈阳—期中
7. 某未知溶液X可能含有、、、、、、中的若干种，取该溶液进行如图所示实验。实验过程中所加试剂均过量，产生的气体全部逸出。下列说法正确的是

A．原溶液至少含有Ca2+、K+、Na+中的一种离子
B．原溶液中一定存在、、和至少0.01 molCl-
C．原溶液中一定存在Na+，且n(Na+)≥0.03 mol
D．原溶液最多可能含有上述离子中的6种
参考答案
见要点（建议与原卷答案核对）
解析
本题是离子推断与定量结合：先由「加 BaCl₂ 得沉淀 8.60 g、加盐酸后剩余 4.66 g」判断 —— 不溶于盐酸的 4.66 g 为 BaSO₄（0.02 mol），溶于盐酸并放气的 3.94 g 为 BaCO₃（0.02 mol），故原溶液含 SO₄²⁻、CO₃²⁻，且不含与它们生成沉淀的 Ca²⁺、Ba²⁺。再由「加 NaOH 产生气体 1.12 L（标况）」得 NH₄⁺ 为 0.05 mol。焰色试验呈黄色（未透过蓝色钴玻璃）说明一定含 Na⁺、K⁺ 不能确定。最后用电荷守恒：正电荷总数 = 2×0 + 0.05(NH₄⁺) + n(Na⁺)，负电荷 = 2×0.02×2 = 0.08 mol，故 n(Na⁺) ≥ 0.03 mol。据此逐项判断 A~D。
易错点
① 忘记「未透过蓝色钴玻璃」意味着钾离子无法确定；② 加 BaCl₂ 引入了 Cl⁻，后续不能据此判断原溶液含 Cl⁻；③ 漏用电荷守恒，导致 Na⁺ 的下界算不出。
讲评要点
把推断题拆成「定性排除 → 定量算物质的量 → 电荷守恒补缺口」三板斧，特别提醒：加入的试剂本身带进来的离子不能算作原溶液的离子。

A．图(1)中的pH数据也可用pH试纸测得
B．根据图(1)(2)的数据可知，HClO光照分解产生了HCl
C．根据图(3)的数据可知，光照使水分解，导致增多
D．若停止光照，溶液pH、氯离子浓度和氧气的体积分数会立即恢复如初
参考答案
B
解析
光照氯水发生 2HClO =(光照) 2HCl + O₂↑。A：氯水有漂白性且需精确 pH 数据，不能用 pH 试纸（会被漂白、读数也不精确），错。B：图中 pH 下降（H⁺ 增多）且 Cl⁻ 浓度上升，说明 HClO 分解生成了 HCl，正确。C：O₂ 体积分数上升来自 HClO 分解，不是「光照使水分解」，错。D：HClO 分解是不可逆过程，停止光照后各量不会「立即恢复如初」，错。
易错点
把 O₂ 的来源误判为水的光解；把可逆/不可逆与「停止条件后是否恢复」混淆。
讲评要点
用传感器曲线讲「证据链」：pH↓ + c(Cl⁻)↑ + φ(O₂)↑ 三条曲线同时出现，只能由一个反应 2HClO → 2HCl + O₂↑ 解释。这也是数字化实验题的通用读图法。

解析
甲为 Cl₂，乙为 Fe，B 为 H₂O，A 为 HCl（溶于水得盐酸），C 为 FeCl₃ 或 HCl 相关产物，D 为 NaClO（84 消毒液有效成分），E 为 Ca(ClO)₂（漂白粉有效成分），丙为 HClO 光照分解产生的 O₂。(1) A 溶于水得无色盐酸；D 为 NaClO；C→丙可写 MnO₂ + 4HCl(浓) =(Δ) MnCl₂ + Cl₂↑ + 2H₂O 或对应的实验室制氯气反应。(2) 饱和氯水滴在 pH 试纸中部，中间先变红后变白、外圈呈红色：使变红的是 H⁺，使变白的是 HClO；说明氯水既有酸性又有漂白性，且不能用 pH 试纸准确测其 pH。(3) 滴加米醋（提供 H⁺）后 84 消毒液漂白/消毒效果增强，是因为 ClO⁻ + H⁺ ⇌ HClO，HClO 浓度增大；对照组为加蒸馏水的同浓度 84 消毒液。
易错点
把漂白粉有效成分写成 CaCl₂ 或 HClO；把「84 加酸效果增强」说成「生成了 Cl₂」而不提 HClO 浓度增大。
讲评要点
用「价—类二维图」把 Cl 的 −1 / 0 / +1 / +4 价物质连成一张网，再让学生把 D、E、丙逐个填进图里。转化关系题先定「突破口」（黄绿色气体、生活中最广泛的金属、相对分子质量最小的氧化物），其余自然推出。

✎ 变式巩固（原创，答案点击展开）

原创变式 1｜写出实验室用 MnO₂ 与浓盐酸制 Cl₂ 的化学方程式，并依次说明饱和食盐水、浓硫酸、NaOH 溶液三处装置的作用；若把 MnO₂ 换成 KMnO₄，装置要怎么改？

MnO₂ + 4HCl(浓) =(Δ) MnCl₂ + Cl₂↑ + 2H₂O。饱和食盐水：除 HCl（并抑制 Cl₂ 溶解）；浓硫酸：干燥 Cl₂；NaOH 溶液：吸收尾气 Cl₂，防止污染。换成 KMnO₄ 后反应在常温下即可进行，可撤去酒精灯（不加热），方程式 2KMnO₄ + 16HCl(浓) = 2KCl + 2MnCl₂ + 5Cl₂↑ + 8H₂O。

原创变式 2｜新制氯水滴入紫色石蕊试液，先变红后褪色；久置氯水漂白性消失。解释这两个现象，并写出相关方程式。

Cl₂ + H₂O ⇌ HCl + HClO。HCl 电离出 H⁺ 使石蕊变红；HClO 有强氧化性，把有色物质氧化而褪色。久置时 2HClO =(光照) 2HCl + O₂↑，HClO 分解殆尽，氯水最终变成稀盐酸，故漂白性消失、酸性增强。
