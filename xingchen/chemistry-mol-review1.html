公式细读

四条公式的适用条件

公式适用条件易错提醒
n = N / NAN 为粒子数，须指明粒子种类NA≈6.02×10²³ mol⁻¹，有单位
n = m / MM 单位 g/mol，数值等于式量质量与物质的量不是同一物理量
n = V / Vm标准状况（0 ℃、101 kPa）下的气体Vm≈22.4 L/mol；标况下水是液体
n = c · V(溶液)V 是溶液体积，单位 L不是溶剂体积，也不能把两者相加
做题顺序：看条件（状态、温度压强、体积含义）→ 求 n → 求所求量。四个公式里只有 V/Vm 附带「标况 + 气体」两个限制，最常出错。

四道即时判分选择题

① 标况下 11.2 L CO₂ 的物质的量是（　）
A．0.25 molB．0.5 molC．1 molD．2 mol
n = 11.2/22.4 = 0.5 mol；注意条件是标准状况。
② 配 500 mL 0.2 mol/L NaCl 需 NaCl（　）
A．0.1 molB．0.2 molC．0.5 molD．1 mol
n = c·V = 0.2×0.5 = 0.1 mol；体积要化成 L。
③ 4 g NaOH 配成 500 mL 溶液，c 为（　）
A．0.1 mol/LB．0.2 mol/LC．0.4 mol/LD．1 mol/L
n = 4/40 = 0.1 mol，c = 0.1/0.5 = 0.2 mol/L。
④ 下列说法正确的是（　）
A．标况 22.4 L 水为 1 molB．1 mol NaCl 含 NA 个分子C．取出部分溶液浓度不变D．气体体积比等于 M 之比
A 水为液体；B 离子晶体无分子；D 同温同压下体积比等于物质的量之比。

综合题

从质量到体积再到浓度

题：8.8 g CO₂，求①物质的量；②标准状况下的体积；③若全部溶于水配成 250 mL 溶液，求物质的量浓度。
点击下方按钮，逐步展开解题过程
第 1 步　n = m/M = 8.8/44 = 0.2 mol
第 2 步　V = n·Vm = 0.2×22.4 = 4.48 L（标准状况）
第 3 步　c = n/V(溶液) = 0.2/0.25 = 0.8 mol/L
三问共用同一个 n：这就是「以 n 为枢纽」的含义。

归纳

第 1 课时小结

1.　四个公式都连着 n，先求 n 再求其他量。
2.　V/Vm 只用于标准状况下的气体，先查状态与条件。
3.　c = n/V 中的 V 是溶液体积，不是溶剂体积。
4.　N 要指明粒子种类，按化学式下标放大。
下一课时：用 NA 判断常见陷阱，并复习一定物质的量浓度溶液的配制与误差分析。
