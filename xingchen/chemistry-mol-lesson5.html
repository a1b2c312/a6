流程

七步流程总览

按上课顺序逐条点亮
① 计算：需要溶质多少克
② 称量：天平称取（精确到 0.1 g）
③ 溶解：烧杯中加水、玻璃棒搅拌
④ 冷却：恢复到室温
⑤ 转移：玻璃棒引流，洗涤 2～3 次
⑥ 定容：近线改滴管，平视相切
⑦ 摇匀装瓶：颠倒摇匀、贴标签
记忆口诀：算称溶冷转洗定摇
每一步都在防一类误差：③④ 防体积误差，⑤ 防溶质损失，⑥ 防定容偏差。

步骤 ①②

计算与称量 · 现场算

配制 100 mL 1.00 mol/L NaCl 溶液
n = c · V = 1.00 × 0.100 = 0.100 mol
m = n · M = 0.100 × 58.5 = 5.85 g
托盘天平只能读到 0.1 g，故实际称 5.9 g。
两道题，现场判分
① 配制 250 mL 0.4 mol/L NaOH，需 NaOH 几 g？（M=40）
② 需用多大规格的容量瓶？（填 mL）
容量瓶只有固定规格，配 100 mL 就选 100 mL，不能用大瓶配小量。

步骤 ③④⑤

溶解 · 冷却 · 转移洗涤

点击每一步，看操作要点与防错理由
③ 溶解
在烧杯中加适量蒸馏水，用玻璃棒搅拌溶解。
不能在容量瓶里直接溶解：溶解常伴随放热，且不便搅拌。
④ 冷却
溶液冷却至室温后再转移。
热溶液定容：冷却后体积收缩，实际 V 偏小，c 偏高。
⑤ 转移与洗涤
玻璃棒引流，下端靠在刻度线以下。
用蒸馏水洗涤烧杯和玻璃棒 2～3 次，洗液全部转入。
少了这一步，溶质损失、n 偏小、c 偏低。

步骤 ⑥

定容：视角决定浓度

红虚线 = 刻度线；蓝色 = 液面
当前：平视（正确）
V 准确 → c 准确
视线与刻度线相平，凹液面最低处与刻度线相切。
操作：加水至距刻度线 1～2 cm 时，改用胶头滴管逐滴加入。
判断口诀：俯视液面低、V 小、c 高；仰视液面高、V 大、c 低。

步骤 ⑦

摇匀 · 装瓶 · 贴标签

摇匀
塞好瓶塞，一手按住塞子、一手托住瓶底，反复上下颠倒摇匀。
摇匀后液面可能略低于刻度线，属正常现象，绝不能再加水——再加水会使 V 偏大、c 偏低。
装瓶与标签
把配好的溶液转移到干净的试剂瓶中，贴上标签，写明溶液名称与浓度（如 NaCl 1.00 mol/L）。
容量瓶不能长期存放溶液，尤其不能存放碱液腐蚀磨口塞。

误差分析

一切回到 c = n / V

点击每一行，看 n 或 V 怎样变、c 往哪走
未洗涤烧杯、玻璃棒
转移时有溶液洒出
未冷却至室温就定容
定容时俯视刻度线
定容时仰视刻度线
摇匀后液面下降再加水
容量瓶洗净后未干燥
砝码与药品放反（用游码）
判断模板：先看溶质有没有损失（定 n），再看最终溶液体积偏大还是偏小（定 V），最后用 c = n/V 收结论。

课堂训练

误差判断 4 题

1. 定容时俯视刻度线，所配浓度（　）
A．偏高B．偏低C．不变D．无法确定
俯视使实际液面低于刻度线，V 偏小，c 偏高。
2. 未洗涤烧杯和玻璃棒，所配浓度（　）
A．偏高B．偏低C．不变D．无法确定
部分溶质残留在烧杯与玻璃棒上，n 偏小，c 偏低。
3. 容量瓶洗净后未干燥，所配浓度（　）
A．偏高B．偏低C．不变D．无法确定
瓶内少量蒸馏水不改变最终定容体积，也不改变溶质的量。
4. 摇匀后液面下降再加水至刻度，浓度（　）
A．偏高B．偏低C．不变D．无法确定
相当于额外加水稀释，V 偏大，c 偏低。

归纳

这节课，我们学会了什么

1.　容量瓶有固定规格、一条刻度线，用前检漏；不能在其内溶解、不能装热溶液、不能久存。
2.　七步：计算、称量、溶解、冷却、转移洗涤、定容、摇匀装瓶贴标签。
3.　定容近线改用胶头滴管，平视使凹液面最低处与刻度线相切。
4.　误差一律回到 c = n/V：俯视 V 小 c 高，仰视 V 大 c 低；溶质损失 n 小 c 低。
本单元到此结束。建议用一张关系图把 N、m、V(g)、c 与 n 的四个公式串起来复习。
