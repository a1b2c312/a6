课堂课件

CLASSWARE
🧂

钠及其化合物 · 第1课时（交互课件）

金属钠的物理性质、钠与非金属（O₂ / Cl₂ / S）的反应、钠与水（盐溶液）的反应。可点击"切钠""点燃""钠入水"等互动实验动画，"浮熔游响红"逐条点亮，附 4 道即时判分课堂小测。← → 键翻页。
🟢

富集在海水中的元素 · 氯（三册合一交互课件）

第一册 性质与用途：1774 年舍勒发现氯气、"烟"与"雾"辨析、与金属 / 非金属 / 水 / 碱的反应；第二册 氯水的成分探究：新制氯水的微粒组成、漂白性与见光分解；第三册 实验室制法：MnO₂ 与浓盐酸、KMnO₄、KClO₃ 三套装置对比与尾气处理。配多组化学方程式与随堂判断题。
🧮

物质的量 · 第1课时 物质的量和阿伏加德罗常数

从生活里的「集合单位」类比建立物质的量 n 与 1 mol，逐级放大感受 6.02×10²³；辨析哪些说法能用 mol 计量，掌握 n = N/N_A 与按化学式下标拆粒子。含随堂判分训练，← → 键翻页。
📐

物质的量 · 第2课时 摩尔质量与气体摩尔体积

从相对分子质量到摩尔质量 M，拖动滑块现场算 n = m/M；对比 1 mol 不同物质的体积，建立 V_m 与 22.4 L/mol 的适用条件，用阿伏加德罗定律完成质量 ↔ 体积综合换算。
🔢

物质的量 · 第3课时 阿伏加德罗常数的应用

一张图看清「所有换算都要经过 n」；逐条破解五大陷阱：物质状态、是否标准状况、粒子种类、氧化还原电子转移、特殊粒子。配电子数 / 共价键计算器与速查表。
💧

物质的量 · 第4课时 物质的量浓度

c_B = n_B / V 逐块拼起来，辨清分母 V 是谁的体积、取出多少浓度都不变；拖动双滑块验证 c₁V₁ = c₂V₂，掌握离子浓度与质量分数 w 的换算。
🧴

物质的量 · 第5课时 一定物质的量浓度溶液的配制

点击容量瓶部件看作用，记住四条使用规矩；七步流程：计算 → 称量 → 溶解冷却 → 转移洗涤 → 定容 → 摇匀装瓶贴标签。含俯视 / 仰视误差动画与七步排序挑战。
🎬
