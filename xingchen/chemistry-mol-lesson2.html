温故

从相对分子质量到摩尔质量

逐行点击，把式量与摩尔质量对上
H₂O：式量 18 → M = 18 g/mol
CO₂：式量 44 → M = 44 g/mol
NaCl：式量 58.5 → M = 58.5 g/mol
H₂SO₄：式量 98 → M = 98 g/mol
规律：以克为单位时，M 的数值 = 式量
摩尔质量 M：单位物质的量的物质所具有的质量，单位 g/mol。
1 mol 任何粒子集合体的质量以克计时，数值恰好等于其相对原子（分子）质量。

点击逐条点亮，弄清原因
固、液体粒子挨得很近，体积主要由粒子本身大小决定
气体粒子间距约为粒子直径的十倍，粒子本身可忽略
所以气体体积主要由粒子间距决定
同温同压下，各种气体的粒子间距近似相同
结论：同温同压下 1 mol 任何气体体积近似相同

核心概念

气体摩尔体积 V_m

V_m = V / n
单位物质的量的气体所占的体积，常用单位 L/mol。
它的大小取决于温度和压强，不是固定常数。
在标准状况（0 ℃、101 kPa）下：
V_m ≈ 22.4 L/mol
22.4 的两个前提，缺一不可
① 必须是标准状况（0 ℃、101 kPa）
② 研究对象必须是气体（含混合气体）
标况体积滑块
n = 1.0 mol
V = n × 22.4
22.4 L

定律

阿伏加德罗定律

同温、同压下，相同体积的任何气体，含有相同数目的分子
点击逐条推出常用推论（同温同压）
V₁ : V₂ = n₁ : n₂　（体积比 = 物质的量之比）
ρ₁ : ρ₂ = M₁ : M₂　（密度比 = 摩尔质量之比）
同体积时，m₁ : m₂ = M₁ : M₂
同质量时，V 与 M 成反比
记忆：气体体积只由「有多少堆分子」和「间距」决定，与分子本身大小几乎无关。

课堂训练

综合换算 · 质量 ↔ 体积

1. 44 g CO₂ 在标况下的体积是（　）
A．11.2 LB．22.4 LC．44.8 LD．无法确定
n = 44/44 = 1 mol，V = 1×22.4 = 22.4 L。
2. 标况下 11.2 L O₂ 的质量是（　）
A．8 gB．16 gC．32 gD．64 g
n = 11.2/22.4 = 0.5 mol，m = 0.5×32 = 16 g。
3. 下列说法正确的是（　）
A．1 mol 任何物质标况下都是 22.4 LB．标况下 1 mol 水约 22.4 LC．标况下 1 mol 混合气体约 22.4 LD．常温 1 mol O₂ 是 22.4 L
只适用于气体，混合气体同样适用；水在标况下是液体。
4. 同温同压下，等质量的 O₂ 与 H₂ 体积比（　）
A．1:1B．1:16C．16:1D．32:1
n = m/M，体积比等于 n 比 = (1/32):(1/2) = 1:16。
解题通法：一切先换算成 n —— 质量用 n=m/M，气体体积用 n=V/V_m，n 是枢纽。

易错清单

这四条，考试最爱考

① 把 22.4 当成万能常数
它只在标况 + 气体时成立。
② 忘记标况下水不是气体
水、酒精、CCl₄、SO₃ 标况下都不是气体。
③ 把 M 当成有单位「个」
M 单位是 g/mol，数值等于式量。
④ 质量与物质的量混为一谈
1 mol 不同物质质量不同，但粒子数相同。
一张关系图记牢：
N ⇄ n ⇄ m　用 N_A 与 M 连接；n ⇄ V(g)　用 V_m 连接。
所有箭头都必须经过 n，不能直接从质量跳到气体体积。

归纳

这节课，我们学会了什么

1.　摩尔质量 M：以 g/mol 为单位时数值等于式量，n = m / M。
2.　气体体积由粒子间距决定；同温同压下 1 mol 任何气体体积近似相同。
3.　V_m = V/n；标准状况（0 ℃、101 kPa）下 V_m ≈ 22.4 L/mol，只用于气体。
4.　阿伏加德罗定律：同温同压同体积的气体含相同分子数；V 比 = n 比。
