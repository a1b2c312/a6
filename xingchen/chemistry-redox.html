一、价态规律

RULES OF VALENCE
①

最高价只有氧化性，最低价只有还原性

规律元素处于最高价态时，化合价只能降低，所以只有氧化性； 处于最低价态时，化合价只能升高，所以只有还原性； 处于中间价态时，既可能升高也可能降低，兼有氧化性和还原性。
典 型 实 例
· 硫元素：H2SO4 中 S 为 +6（最高价）→ 浓硫酸只表现氧化性；
  H2S 中 S 为 −2（最低价）→ 硫化氢只表现还原性；
  SO2 中 S 为 +4（中间价）→ 既可被氧化成 +6，又可被还原成 0。
· 氮元素：HNO3（+5）只有氧化性；NH3（−3）只有还原性；N2（0）兼有。
②

化合价不跳过中间价

规律同一元素有三种或三种以上价态时，不同价态之间发生反应， 化合价的升降只能"就近"变化，不能跳过中间的价态。
由此派生出两类重要反应：
歧化反应同一种元素既升高又降低（自身氧化还原），中间价态转化为较高价和较低价两个价态。
归中反应同种元素的高价与低价相互靠拢，最终都变成中间价（只相向而行，绝不交叉）。
典 型 实 例
· 歧化：Cl2 + 2NaOH = NaCl + NaClO + H2O
  Cl 由 0 价 升高到 +1，同时 降低到 −1，中间价"一分为二"。
· 归中：2H2S + SO2 = 3S↓ + 2H2O
  S 由 −2 与 +4 相向而行，都变成 0 价，不会越过 0 价变成对方的价态。
· 不跳价：H2S + H2SO4(浓) = S↓ + SO2↑ + 2H2O
  −2 价只能升到 0，+6 价只能降到 +4，各自"就近"变化，不跳过中间的 0 价与 +4 价。
③

化合价变化有升必有降

规律氧化还原反应的实质是电子转移，得电子总数一定等于失电子总数。 因此元素化合价有升高就必定有降低，且升高总数 = 降低总数。
这也是配平氧化还原方程式、进行电子守恒计算的根本依据：可以先数出某元素升高的总数，再去找相应元素降低的总数。
典 型 实 例
· Fe + CuSO4 = FeSO4 + Cu
  Fe 由 0 升高到 +2（失去 2e−），Cu 由 +2 降低到 0（得到 2e−），升降总数相等。
· 2Na + 2H2O = 2NaOH + H2↑
  Na 升高到 +1（失 2e−），H 由 +1 降到 0（得 2e−），始终"有升有降、升=降"。

小结：判断氧化性／还原性先看价态高低，判断反应能否发生先看是否跳过中间价，配平与计算则抓住升降相等。

巩 固 练 习 一
对于反应 KClO3 + 6HCl(浓) = KCl + 3Cl2↑ + 3H2O，请回答：
(1) 氧化剂是______，还原剂是______；
(2) 氧化产物与还原产物分别是______；
(3) 被氧化的氯原子与被还原的氯原子的个数比为______。
查看答案与解析
答案(1) 氧化剂 KClO3，还原剂 HCl；(2) 氧化产物和还原产物都是 Cl2；(3) 5 : 1。

解析先标价态：KClO3 中 Cl 为 +5，HCl 中 Cl 为 −1，生成物 Cl2 中 Cl 为 0。
① KClO3 中的 Cl 由 +5 降到 0，得电子被还原，故 KClO3 是氧化剂，对应的还原产物是 Cl2；
② HCl 中的 Cl 由 −1 升到 0，失电子被氧化，故 HCl 是还原剂，对应的氧化产物也是 Cl2；
③ 注意 KCl 中的 Cl 仍为 −1，没有变价，所以它既不是氧化产物也不是还原产物。
由"有升必有降、升降相等"可算出：1 个 +5 的 Cl 要得到 5 个电子，则需要 5 个 −1 的 Cl 各失去 1 个电子， 因此被氧化的氯原子 : 被还原的氯原子 = 5 : 1（方程式中 6 个 HCl 里有 5 个被氧化、1 个与 K+ 结合成 KCl）。

二、强弱规律

THE STRONGER WINS
规

强制弱

核心氧化还原反应总是由强到弱进行：
强氧化剂 + 强还原剂 → 弱氧化剂（氧化产物）+ 弱还原剂（还原产物）
也就是说：氧化剂的氧化性 > 氧化产物的氧化性；还原剂的还原性 > 还原产物的还原性。
反应物的"强"与生成物的"弱"，是判断一切氧化还原问题的出发点。
常 见 强 弱 顺 序（供比较）
· 氧化性（酸性条件下）：MnO4− > Cl2 > Br2 > Fe3+ > I2 > S
· 还原性：S2− > SO32− > I− > Fe2+ > Br− > Cl−
注：强弱顺序与浓度、温度、酸碱性有关，如 MnO4− 要在酸性条件下才表现强氧化性。
①

判断强弱

方法由反应方向反推强弱：写出一个已知能发生的反应， 反应物中氧化剂一方的氧化性一定强于氧化产物一方；还原剂一方的还原性一定强于还原产物一方。
反过来，把多个反应"串"起来，就能排出整套强弱顺序。
典 型 实 例
· Cl2 + 2NaBr = 2NaCl + Br2
  氧化性：Cl2 > Br2；还原性：Br− > Cl−。
· 2Fe3+ + 2I− = 2Fe2+ + I2
  氧化性：Fe3+ > I2；还原性：I− > Fe2+。
· 串联：由 Cl2 > Br2、Br2 > Fe3+、Fe3+ > I2 可得 Cl2 > Br2 > Fe3+ > I2。
②

判断反应是否能发生

方法把给出的反应按"强 + 强 → 弱 + 弱"对号入座： 反应物中的氧化剂必须是参加比较的较强一方，才可能发生； 若写成"较弱的一方去氧化较强的还原产物"，就不能发生。
另外注意：如果一种氧化剂同时遇到多种还原剂，先氧化还原性最强的那种（优先反应）。
典 型 实 例
· Cl2 + 2KI = 2KCl + I2　✅ 能发生
  因为氧化性 Cl2 > I2，Cl2 可以把 I− 氧化成 I2。
· I2 + 2NaCl → 不反应　❌ 不能发生
  因为氧化性 I2 < Cl2，I2 无法把 Cl− 氧化成 Cl2。
· 2Fe3+ + Cu = 2Fe2+ + Cu2+　✅ 能发生（氧化性 Fe3+ > Cu2+）
· 2Fe3+ + 2Br− → 不反应　❌（氧化性 Fe3+ < Br2，所以 Br− 不能被 Fe3+ 氧化）

小结：一、价态规律解决"谁有氧化性、谁有还原性"；二、强弱规律解决"谁的氧化性更强"与"这个反应能不能发生"。

巩 固 练 习 二
已知下列反应均能发生：
① Cl2 + 2NaBr = 2NaCl + Br2
② 2FeCl3 + 2NaI = 2FeCl2 + I2 + 2NaCl
③ Br2 + 2Fe2+ = 2Br− + 2Fe3+
(1) 请排出 Cl2、Br2、Fe3+、I2 四种微粒氧化性由强到弱的顺序；
(2) 判断反应 I2 + 2Fe2+ → 能否发生，并说明理由。
查看答案与解析
答案(1) 氧化性：Cl2 > Br2 > Fe3+ > I2；(2) 不能发生。

解析依据"强制弱"，由每个反应中"氧化剂强于氧化产物"逐条反推：
① 氧化剂是 Cl2、氧化产物是 Br2，得 Cl2 > Br2；
② 氧化剂是 Fe3+、氧化产物是 I2，得 Fe3+ > I2；
③ 氧化剂是 Br2、氧化产物是 Fe3+，得 Br2 > Fe3+；
三条串联即得 Cl2 > Br2 > Fe3+ > I2（对应还原性为 I− > Fe2+ > Br− > Cl−）。
(2) 若 I2 作氧化剂去氧化 Fe2+，就必须满足"氧化性 I2 > Fe3+"， 而由 (1) 可知实际上 I2 < Fe3+，不满足"强制弱"，因此该反应不能发生。

三、先后规律

THE STRONGEST GOES FIRST
规

强者优先，竞争反应的先后顺序

核心向混合体系中加入某一种氧化剂（或还原剂）时，它会先和还原性最强（或氧化性最强）的那种微粒反应， 等它反应完，才轮到次强的。
也就是说："谁能把对方氧化得最彻底"并不重要，还原性（氧化性）最强的先反应——这就是先后顺序的判据。
少量／过量（足量）试剂的产物不同，根源就在这个先后顺序上。
典 型 实 例
· 还原性顺序决定先后：向 FeBr2 溶液中通入 Cl2。因为还原性 Fe2+ > Br−，
  少量 Cl2 只先氧化 Fe2+：2Fe2+ + Cl2 = 2Fe3+ + 2Cl−；
  足量 Cl2 再氧化 Br−：2Fe2+ + 4Br− + 3Cl2 = 2Fe3+ + 2Br2 + 6Cl−。
· 混合液中先析出谁：向 NaI 与 NaBr 的混合液中通入少量 Cl2，因为还原性 I− > Br−，
  首先析出 I2，而不是 Br2。
· 氧化性顺序决定先后：向含 Fe3+、Cu2+ 的溶液中加入铁粉，因为氧化性 Fe3+ > Cu2+，
  Fe 先与 Fe3+ 反应（2Fe3+ + Fe = 3Fe2+），剩余的 Fe 才去置换 Cu2+。

小结：一、二两章解决"谁强谁弱"，三章解决"谁先谁后"。排先后时先排出强弱顺序， 再把加入的试剂按顺序"分配"给最强的微粒，注意少量与足量产物不同。

巩 固 练 习 三
向 FeBr2 溶液中通入一定量的 Cl2，请回答：
(1) 通入少量 Cl2 时，发生反应的离子方程式：______；
(2) 通入足量 Cl2 时，发生反应的离子方程式：______；
(3) 若溶液中有一半的 Br− 被氧化，此时通入的 Cl2 与被氧化的 Fe2+ 的物质的量之比为______。
查看答案与解析
答案
(1) 2Fe2+ + Cl2 = 2Fe3+ + 2Cl−
(2) 2Fe2+ + 4Br− + 3Cl2 = 2Fe3+ + 2Br2 + 6Cl−
(3) 1 : 1

解析关键是比较还原性强弱：还原性 Fe2+ > Br− （因为氧化性 Br2 > Fe3+），所以 Cl2 先氧化 Fe2+，后氧化 Br−。
(1) 少量 Cl2 只能氧化部分 Fe2+，Br− 尚未参与反应。
(2) 足量 Cl2 把 Fe2+ 与 Br− 全部氧化，按 FeBr2 中 Fe2+ : Br− = 1 : 2 配平， 可得 Fe2+、Br−、Cl2 的化学计量数之比为 2 : 4 : 3。
(3) 设 FeBr2 为 1 mol，则 Fe2+ 为 1 mol、Br− 为 2 mol。 "一半 Br− 被氧化"意味着 Fe2+ 必须先全部被氧化（1 mol），随后 Br− 被氧化 1 mol。
  由电子守恒，失去的电子总数 = 1 mol × 1 + 1 mol × 1 = 2 mol； 每 1 mol Cl2 得 2 mol 电子，故通入的 Cl2 为 1 mol。
  因此通入的 Cl2 : 被氧化的 Fe2+ = 1 mol : 1 mol = 1 : 1。

四、守恒规律

CONSERVATION
导

为什么要守恒

总纲氧化还原反应的实质是电子转移：有元素失去电子，就必有元素得到电子，且 失电子总数 = 得电子总数。反映到化合价上，就是升高总数 = 降低总数； 而溶液与离子方程式中还始终保持电荷守恒。这三条守恒律，是配平方程式、进行定量计算的通用工具。
①

化合价升降相等

规律反应中所有元素化合价升高总数 = 降低总数。常用于"已知一种元素的价态变化，求另一种元素的量或化学计量数"。
思 路
① 标出变价元素反应前后的价态；② 算出每种元素单个原子的升降数值； ③ 按"升降相等"列式：升高值 × 被氧化原子数 = 降低值 × 被还原原子数。
对 应 练 习 ①
铜与稀硝酸反应：3Cu + 8HNO3(稀) = 3Cu(NO3)2 + 2NO↑ + 4H2O。
若 1 mol Cu 完全反应，求被还原的硝酸（即生成 NO 的硝酸）的物质的量。
查看答案与解析
答案2/3 mol（约 0.67 mol）

解析标价态：Cu 由 0 → +2，每个铜原子升高 2； N 由 +5 → +2（生成 NO），每个氮原子降低 3。
设被还原的硝酸为 x mol，由化合价升降相等：
1 mol × 2 = x × 3　解得 x = 2/3 mol。
注意：8 个 HNO3 中只有 2 个被还原（生成 NO），其余 6 个起酸性作用生成 Cu(NO3)2， 所以被还原的硝酸不等于参加反应的硝酸总量（用升降相等列式，可避免这个陷阱）。
②

得失电子守恒

规律还原剂失去电子的总数 = 氧化剂得到电子的总数。
电子转移的数目 = 化合价升降的数值 × 对应原子的物质的量。它是氧化还原计算题最常用的"通用钥匙"： 只要抓住"转移电子数相等"，往往一步就能列式求解。
思 路
① 找出失电子的物质（还原剂）与得电子的物质（氧化剂）； ② 算出转移电子总数（如某元素升高 3 价 × 3 mol = 9 mol e−）； ③ 让"失 = 得"列方程求解。
对 应 练 习 ②
一定量的铁与足量稀硝酸反应，生成标准状况下 2.24 L 的 NO，且铁全部转化为 Fe3+。 求参加反应的铁的物质的量。（标准状况下气体摩尔体积取 22.4 L/mol）
查看答案与解析
答案0.1 mol

解析先求 NO 的物质的量：n(NO) = 2.24 L ÷ 22.4 L/mol = 0.1 mol。
N 由 +5 → +2，每个氮原子得到 3 个电子，故得电子总数 = 0.1 mol × 3 = 0.3 mol。
Fe 由 0 → +3，每个铁原子失去 3 个电子。设铁为 n mol，则失电子总数 = 3n mol。
由得失电子守恒：3n = 0.3　解得 n = 0.1 mol。
（即反应为 Fe + 4HNO3 = Fe(NO3)3 + NO↑ + 2H2O，1 mol Fe 恰好生成 1 mol NO。）
③

电荷守恒

规律① 任何电中性的溶液中，阳离子所带正电荷总数 = 阴离子所带负电荷总数；
② 任何离子方程式，等号两边的电荷代数和一定相等。
常用于：由离子浓度求未知离子浓度、检查离子方程式是否书写正确。
思 路
· 溶液电中性：Σ c(阳离子) × 所带电荷数 = Σ c(阴离子) × 所带电荷数
· 离子方程式：左边各离子电荷代数和 = 右边各离子电荷代数和
对 应 练 习 ③
某溶液中只含有 Na+、Mg2+、Cl−、SO42− 四种离子， 已知 c(Na+) = 0.2 mol/L、c(Mg2+) = 0.1 mol/L、c(Cl−) = 0.2 mol/L。
求 c(SO42−)。（忽略水的电离）
查看答案与解析
答案0.1 mol/L

解析溶液呈电中性，阳离子所带正电荷总数等于阴离子所带负电荷总数：
c(Na+) + 2c(Mg2+) = c(Cl−) + 2c(SO42−)
代入数据：0.2 + 2 × 0.1 = 0.2 + 2x　→　0.4 = 0.2 + 2x　→　x = 0.1 mol/L。
常见错误是忘记把离子的电荷数乘上去（Mg2+ 要乘 2、SO42− 要乘 2），导致结果出错。

小结：升降相等看化合价，电子守恒看转移数目，电荷守恒看溶液与离子方程式。 三条守恒律各有适用场合，配平与计算时优先想到它们，往往能绕开繁琐的中间步骤。

综合巩固

MIXED PRACTICE

本题综合考查：歧化反应与还原剂判断（一章②）、双线桥表示电子转移（四章①②）、离子方程式书写与缺项配平（四章③）。

综

氧化亚铜与高铁酸钠

(1) 氧化亚铜（Cu2O）是一种鲜红色粉末状固体，几乎不溶于水，可在酸性溶液中发生反应，与硫酸、硝酸的反应如下：
ⅰ. Cu2O + H2SO4 = CuSO4 + Cu + H2O
ⅱ. 3Cu2O + 14HNO3(稀) = 6Cu(NO3)2 + 2NO↑ + 7H2O
① 反应ⅰ中还原剂为______（填化学式，下同），还原产物为______。
② 用双线桥标出反应ⅱ中电子转移的方向和数目。
③ 请写出反应ⅱ的离子方程式：______。
(2) 高铁酸钠（Na2FeO4）有强氧化性，可以有效杀灭水中的细菌和病毒。 已知湿法制备高铁酸钠的反应体系有六种微粒：Fe(OH)3、ClO−、OH−、 FeO42−、Cl−、H2O。写出并配平湿法制备高铁酸钠的离子方程式：______。
查看答案与解析
① 答案还原剂：Cu2O；还原产物：Cu。

解析Cu2O 中 Cu 为 +1 价，反应ⅰ中一部分升到 +2（CuSO4）， 一部分降到 0（Cu 单质）——同一元素的歧化反应。化合价升高的部分是还原剂（Cu2O）， 化合价降低后得到的产物是还原产物（Cu）。

② 答案双线桥的"桥"画在反应物与生成物中同种元素之间，箭头上标注电子数目：
· 失去 6e−：Cu2O 中的 Cu（+1）→ Cu(NO3)2 中的 Cu（+2）， 共 6 个 Cu 各失去 1 个 e−；
· 得到 6e−：HNO3 中的 N（+5）→ NO 中的 N（+2）， 共 2 个 N 各得到 3 个 e−。
两条桥上电子数目相同（6e−），这正是"得失电子守恒"的体现。

③ 答案3Cu2O + 14H+ + 2NO3− = 6Cu2+ + 2NO↑ + 7H2O

解析先把化学方程式拆成离子：Cu2O、NO、H2O（写化学式）， 强酸 HNO3 拆成 H+ 与 NO3−，可溶盐 Cu(NO3)2 拆成 Cu2+ 与 NO3−； 消去两边未变价的 NO3−（左边 12 个、右边 12 个）后，剩下的 2 个 NO3− 参与氧化还原。
用电荷守恒自查：左边 14(+1) + 2(−1) = +12，右边 6 × (+2) = +12 ✓；电子守恒：失 6e− = 得 6e− ✓。

(2) 答案2Fe(OH)3 + 3ClO− + 4OH− = 2FeO42− + 3Cl− + 5H2O

解析这是典型的缺项配平，四步走：
① 定变价：Fe 由 Fe(OH)3 中的 +3 → +6（FeO42−）， 每个铁失 3e−；Cl 由 ClO− 中的 +1 → −1（Cl−）， 每个氯得 2e−；
② 电子守恒定系数：最小公倍数 6，故 Fe(OH)3 系数为 2、ClO− 系数为 3， 得 2FeO42− 和 3Cl−；
③ 电荷守恒补微粒：右边电荷 2×(−2) + 3×(−1) = −7，左边已知 3×(−1) = −3， 左边还缺 −4，需在左边补 4 个 OH−（碱性体系）；
④ 质量守恒补水：H 左边 2×3 + 4 = 10 个，右边补 5H2O（O 也恰好平：6+3+4 = 13 = 8+5）✓。
