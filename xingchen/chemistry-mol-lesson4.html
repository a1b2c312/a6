导入

为什么需要一种新的浓度

质量分数 w
  • w = m(溶质) / m(溶液)
  • 要称质量，操作较繁
  • 实验室量取体积更方便
  • 化学反应按粒子数（n）配比
物质的量浓度 c_B
  • c_B = n_B / V(溶液)
  • 直接给出「每升含多少 mol」
  • 量取体积即得 n
  • 与化学方程式的系数直接对接
n = c · V

分母 V 到底是谁的体积

点击判断：下列做法对吗
4 g NaOH 加 500 mL 水
4 g NaOH 配成 500 mL
体积 = 水体积 + 固体体积
容量瓶定容至刻度线

1 L 水溶解 1 mol 溶质得 1 mol/L

性质

取出多少，浓度都不变

从 1.0 mol/L NaCl 中取出 V mL
取出体积 V = 100 mL
浓度 c = 1.0 mol/L（始终不变）
含溶质 n = 0.10 mol（随体积变）
溶液是均一的，倒多倒少不改变「浓淡」。
两个量要分清
c 是「浓淡」，与取用量无关；
n 是「有多少」，n = c·V，随取用体积成正比。

稀释

c₁V₁ = c₂V₂ · 拖动双滑块

浓硫酸稀释：c₁ = 18 mol/L
取原液 V₁ = 10 mL
稀释到 V₂ = 100 mL
c₂ = c₁V₁ / V₂
1.80 mol/L
稀释定律的依据
加水只改变溶液体积，溶质的物质的量 n 始终不变。
所以 n = c₁V₁ = c₂V₂。
注意 V₁、V₂ 必须用同一单位。

拓展

质量分数 w 与 c 的换算

c = 1000 ρ w / M
ρ：g/cm³　w：质量分数　M：g/mol　c：mol/L
点击逐条看推导思路
取 1 L 溶液，其质量 = 1000ρ 克
其中溶质质量 = 1000ρ·w 克
溶质物质的量 n = 1000ρw / M
因体积恰为 1 L，故 c = n / 1 = 1000ρw/M
例：98% 浓硫酸 ρ=1.84 g/cm³，M=98 g/mol → c = 1000×1.84×0.98/98 = 18.4 mol/L。

基础 4 题 · 定义与直接计算

1. 4 g NaOH 配成 500 mL 溶液，c 为（　）
A．0.1 mol/LB．0.2 mol/LC．0.4 mol/LD．2 mol/L
n = 4/40 = 0.1 mol，c = 0.1/0.5 = 0.2 mol/L。
2. 配制时把 1 L 水当成 1 L 溶液，结果 c（　）
A．偏高B．偏低C．不变D．无法判断
实际溶液体积大于 1 L，分母偏大，浓度偏低。
3. 从 2 mol/L 溶液中倒出一半，剩余溶液 c（　）
A．1 mol/LB．2 mol/LC．4 mol/LD．无法确定
溶液均一，浓度与取用量无关，仍是 2 mol/L。
4. 0.5 mol/L Na₂SO₄ 中 c(Na⁺) 为（　）
A．0.5 mol/LB．1.0 mol/LC．0.25 mol/LD．2 mol/L
下标 2，c(Na⁺) = 2×0.5 = 1.0 mol/L。

易错清单

四条最容易丢分的地方

① 分母用错体积
必须用配好后的溶液总体积，且换成 L。
② 认为倒出一半浓度减半
c 不变，变的是 n 和 V。
③ 稀释时把 c 相加
只能用 c₁V₁ = c₂V₂，不能把浓度直接平均。
④ 离子浓度漏乘下标
Al₂(SO₄)₃ 中 Al³⁺ 乘 2、SO₄²⁻ 乘 3。
至此四条通路齐了：N ⇄ n ⇄ m、n ⇄ V(g)、n ⇄ c。
无论题目给什么，一律先求 n，再求目标量。

归纳

这节课，我们学会了什么

1.　c_B = n_B / V(溶液)，单位 mol/L；V 是溶液总体积，不是溶剂体积。
2.　浓度与取用量无关，n = c·V 随体积成正比。
3.　稀释前后溶质 n 不变：c₁V₁ = c₂V₂。
4.　离子浓度 = 溶质浓度 × 下标；w 与 c 换算 c = 1000ρw/M。
