规矩一

实验室里，金属钠一旦着火，严禁用水浇、严禁用泡沫灭火器，只能用干燥沙土盖灭。

🛢️
规矩二

实验室的金属钠从不裸露存放，而是浸在煤油里，还要隔绝空气密封保存。

🤔 这两条规矩背后藏着钠的什么"脾气"？

钠的化学性质非常活泼，常温下就能与空气中的氧气、水蒸气反应，遇到水反应更剧烈——这些"规矩"，都由钠的物理性质和化学性质共同决定。这节课我们逐一揭开。

02 钠与非金属的反应

钠与氧气：条件不同，产物不同

实验 1 · 常温
刚才的切面实验

新切面很快失去光泽，生成白色的氧化钠（Na₂O）。

4Na + O₂ = 2Na₂O

实验 2 · 加热点燃
🔥 点燃

钠剧烈燃烧，发出黄色火焰，生成淡黄色的过氧化钠（Na₂O₂）。

2Na + O₂ 点燃= Na₂O₂

结论：反应条件不同，产物不同——常温得 Na₂O（白色），点燃得 Na₂O₂（淡黄色）。这提示我们：书写化学方程式时必须注明反应条件。

钠与非金属的反应钠 + 氧气
02 钠与非金属的反应

Na₂O 与 Na₂O₂：一字之差，两种氧化物

氧化钠 Na₂O过氧化钠 Na₂O₂
颜色状态 白色固体 淡黄色固体
生成条件常温下钠与 O₂ 反应钠点燃 / 加热时与 O₂ 反应
氧元素化合价−2 价−1 价（氧元素的另一种化合价）
类别碱性氧化物过氧化物（不属于碱性氧化物）

书写要点：Na₂O₂ 中 O 为 −1 价，两个氧原子共 −2 价，钠为 +1 价——化合价代数和为零。

关联上一章：这两步反应中钠的化合价都从 0 → +1，失去电子，被氧化——钠是常见的还原剂。

02 钠与非金属的反应

钠与氯气、硫的反应

与氯气 Cl₂（下一章主角）

加热时钠在 Cl₂ 中剧烈燃烧，产生黄色火焰和大量白烟（白烟 = 生成的 NaCl 固体小颗粒）。

2Na + Cl₂ 点燃= 2NaCl

钠从 0 → +1（失电子），氯从 0 → −1（得电子）。

与硫 S

钠与硫化合时甚至会发生爆炸——再次说明钠的还原性很强，能与多种非金属单质直接反应。

2Na + S = Na₂S

研细后混合研磨或加热均可剧烈反应。

小结规律：钠与非金属单质反应，钠都作还原剂，化合价 0 → +1，被氧化；产物都是含 +1 价钠的离子化合物。钠的化学性质由它的原子结构决定：最外层只有 1 个电子，极易失去。

03 钠与水的反应

演示实验：钠投入滴有酚酞的水中

嘶嘶…嘶嘶…
滴有酚酞的水（无色）
⬇️ 将绿豆大的钠投入水中

观察到的每一个现象，点击点亮对应字卡：

浮钠浮在水面上（ρ钠 < ρ水）
熔熔成闪亮小球（反应放热，钠熔点低）
游四处游动（产生的 H₂ 推动小球）
响发出嘶嘶声（反应剧烈，气体逸出）
红溶液变红（生成碱——NaOH 使酚酞变红）

五个现象、五条证据："浮、熔"对应物理性质（密度、熔点），"游、响、红"对应化学变化——钠与水反应生成了新物质 NaOH 和 H₂。

钠与水的反应浮 · 熔 · 游 · 响 · 红
03 钠与水的反应

从现象到本质：方程式与化合价分析

2Na + 2H₂O = 2NaOH + H₂↑

离子方程式：2Na + 2H₂O = 2Na⁺ + 2OH⁻ + H₂↑

化合价分析（双线桥视角）

钠是还原剂：0 → +1，失去电子，被氧化。

水是氧化剂：H 从 +1 → 0，得到电子，被还原。

安全警示：这正是"钠着火不能用水浇"的原因——加水反而剧烈反应产生 H₂，火势更大。

03 钠与盐溶液的反应

钠投入硫酸铜溶液，能置换出铜吗？

CuSO₄ 溶液（蓝色）
⬇️ 将钠投入 CuSO₄ 溶液

先猜一猜：会不会像铁 + 硫酸铜那样析出红色的铜？再点击揭示 👉

点击揭示真相

现象：钠仍浮在液面、熔成小球、四处游动并产生气泡；同时溶液中出现蓝色沉淀。⚠️ 没有红色铜析出！

原因：钠太活泼，进入溶液后先与水反应生成 NaOH 和 H₂，NaOH 再与 CuSO₄ 反应生成蓝色 Cu(OH)₂ 沉淀：

2Na + 2H₂O + CuSO₄ = Cu(OH)₂↓ + Na₂SO₄ + H₂↑

结论：钠与盐溶液反应，不能置换出金属。

钠与盐溶液的反应先水后盐

本课小结

一条主线：钠原子最外层 1 个电子 → 极易失去 → 还原性强

01 物理性质

银白、质软、熔点低（97.8 ℃）、密度小（0.97 g/cm³）、导电导热好。
→ 保存在煤油中。

02 与非金属

O₂：常温 → Na₂O（白），点燃 → Na₂O₂（淡黄）；
Cl₂：白烟；S：甚至爆炸。钠均为还原剂。

03 与水（盐溶液）

2Na+2H₂O=2NaOH+H₂↑
现象：浮、熔、游、响、红；
与盐溶液：先水后盐，不置换金属。

方法提示：描述实验现象时，先"看"（颜色、状态）再"听"（声音），分清物理变化与化学变化的证据；写方程式必须注明条件与状态符号（↑、↓）。
