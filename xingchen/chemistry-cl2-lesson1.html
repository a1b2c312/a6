第一册 · 氯气的性质和用途

一、氯气的发现

1774 年 · 瑞典 · 舍勒 (Scheele)
用二氧化锰与浓盐酸共热，制得一种黄绿色、有刺激性气味的气体，但受当时"燃素说"影响，误认为它是"氧化盐酸"。
1810 年 · 英国 · 戴维 (Davy)
用电池加热等种种方法都不能使它分解，确认它是一种新元素，并命名为 chlorine（源自希腊文"黄绿色"）。中文"氯"取"气"字头表状态、"彔"表绿色。
MnO2 + 4HCl(浓) △ MnCl2 + Cl2↑ + 2H2O
这也是今天实验室制 Cl2 的经典方法——发现史与实验室制法在此交汇。
💡 思考：舍勒制得的气体其实混有 HCl 气体和水蒸气，如何得到纯净干燥的 Cl2？（提示：先通过饱和食盐水，再通过浓硫酸 —— 详见第三册）

二、氯气的泄漏处理

情景：某化工厂液氯储罐泄漏，黄绿色气体向四周弥漫。下列做法对吗？点击卡片看结论。

① 用湿毛巾（最好蘸肥皂水或 Na2CO3 稀溶液）捂住口鼻，逆风向、向高处撤离
✔ 正确：Cl2 能与碱性物质反应而被吸收；Cl2 密度比空气大，会向低洼处聚集，所以要向高处、逆风（或侧风）方向撤离。
② 赶紧躲到低洼的地下室、下水道里
✘ 错误：M(Cl2)=71 > 29，氯气沉在低处，低洼处浓度最高，最危险！
③ 顺着风向拼命奔跑逃离
✘ 错误：顺风跑等于追着毒气跑，应逆风或垂直于风向撤离。
④ 消防员向泄漏区上空喷洒稀 NaOH 溶液或石灰水
✔ 正确：Cl2 + 2NaOH = NaCl + NaClO + H2O，用碱液吸收、形成"水幕"降毒。
⑤ 立即打电话报警，并向上风向居民区疏散人群
✔ 正确：专业处置 + 有序疏散，避免恐慌性拥堵。
⑥ 在家紧闭门窗，认为氯气进不来
✘ 不完整：门窗缝隙挡不住气体；应撤离而非滞留。若无法撤离，可用湿毛巾/湿被褥封堵门缝并在上风房间等待救援。
⚠ 两条底层原理：① 密度比空气大 → 往高处、逆风走；② 能与碱反应 → 用碱性溶液吸收（湿毛巾、石灰水、稀 NaOH）。

闻气体气味的正确操作（扇闻法）

氯气有毒，绝不可把鼻子凑到瓶口直接闻。正确做法：瓶口远离鼻孔，用手在瓶口轻轻扇动，仅使极少量气体飘入鼻孔。

向上排空气法 ✔：Cl2 密度大于空气，且常温下不与 O2、N2 反应。
排水法 ✘（一般不用）：Cl2 能溶于水且与水反应。
但可用「排饱和食盐水法」：饱和食盐水中 Cl− 浓度大，抑制 Cl2 + H2O ⇌ H+ + Cl− + HClO 正向进行，大大降低 Cl2 的溶解损失。

四、氯气的化学性质

Cl2 最核心的身份是强氧化剂（Cl 元素化合价 0 → −1）。点击每张卡，展开现象与方程式。
① 与金属钠反应 —— 剧烈燃烧（点击展开）
2Na + Cl2 点燃 2NaCl
现象：
钠在氯气中剧烈燃烧，产生黄色火焰，生成白烟（NaCl 固体小颗粒），瓶壁附着白色固体。
② 与铁反应 —— 生成高价铁（点击展开）
2Fe + 3Cl2 点燃 2FeCl3
现象：
铁丝在氯气中燃烧，产生棕褐色（棕黄色）的烟，加水后溶液呈黄色。
关键结论：
与变价金属反应，Cl2 生成高价态氯化物（FeCl3 而非 FeCl2），说明 Cl2 氧化性很强。对比：S 与 Fe 反应只得 FeS（低价）。
⚠ 常温下干燥的 Cl2 与铁不反应，所以液氯可用钢瓶储运。
③ 与铜反应 —— 棕黄色的烟（点击展开）
Cu + Cl2 点燃 CuCl2
现象：
红热的铜丝在氯气中剧烈燃烧，产生棕黄色的烟；加水后，浓溶液呈绿色，稀释后呈蓝色（[Cu(H2O)4]2+ 与 [CuCl4]2− 共存所致，了解即可）。
辨析：
"烟"是固体小颗粒，"雾"是小液滴。CuCl2 烟是固体颗粒，故称"烟"。
④ 与氢气反应 —— 燃烧 vs 爆炸（点击展开）
H2 + Cl2 点燃 2HCl　　H2 + Cl2 光照 2HCl
点燃：
H2 在 Cl2 中安静燃烧，发出苍白色火焰，瓶口有白雾（HCl 遇空气中水蒸气形成盐酸小液滴）。工业上用此反应制盐酸。
光照（混合气体）：
剧烈爆炸。
结论：
反应条件不同，现象可能不同；燃烧不一定需要氧气参加（任何发光发热的剧烈化学反应都是燃烧）。
⑤ 与水反应 —— 氯水的由来（点击展开）
Cl2 + H2O ⇌ HCl + HClO　（可逆反应）
要点：
Cl2 既是氧化剂又是还原剂（歧化反应）；生成物 HClO 具有强氧化性（漂白、杀菌）。
提示：
本册只做初步认识，详细成分探究见第二册。
⑥ 与碱反应 —— 漂白液与漂白粉（点击展开）
Cl2 + 2NaOH = NaCl + NaClO + H2O　（制漂白液，84 消毒液主要成分 NaClO）
2Cl2 + 2Ca(OH)2 = CaCl2 + Ca(ClO)2 + 2H2O　（制漂白粉）
漂白粉：
主要成分 CaCl2 与 Ca(ClO)2，有效成分是 Ca(ClO)2。
漂白原理：
Ca(ClO)2 + CO2 + H2O = CaCO3↓ + 2HClO（强酸制弱酸：H2CO3 > HClO）
失效原因：
2HClO 光照 2HCl + O2↑ → 所以漂白粉要密封、避光、干燥保存。
⚠ 生活安全：84 消毒液（NaClO）不能与洁厕灵（HCl）混用！
NaClO + 2HCl = NaCl + Cl2↑ + H2O，会放出有毒氯气。
⑦ 与还原性物质反应 —— 强氧化性的体现（点击展开）
Cl2 + 2FeCl2 = 2FeCl3　（溶液由浅绿色变黄色）
Cl2 + 2KI = 2KCl + I2　（无色→棕褐色；遇淀粉变蓝，用于验满 Cl2）
Cl2 + SO2 + 2H2O = H2SO4 + 2HCl　（氯水与 SO2 混合后漂白性减弱甚至消失）
规律：
Cl2 遇还原性离子（Fe2+、I−、Br−、S2−、SO32−）时，优先表现氧化性，本身被还原为 Cl−。

三、久置氯水

2HClO 光照 2HCl + O2↑

HClO 不断分解，促使 Cl2 + H2O ⇌ HCl + HClO 平衡右移，Cl2 最终消耗殆尽。所以：

久置氯水
浅黄绿色褪去 → 无色；成分相当于稀盐酸：H2O、H+、Cl−、OH−（无 Cl2、HClO、ClO−）
失去的性质
不再有漂白性、不再有 Cl2 的强氧化性；只保留酸性和 Cl−
⚠ 实验室保存新制氯水：盛放在棕色试剂瓶中，置于冷暗处，现用现配。
1 mol Cl2 与水反应只生成 1 mol HCl 和 1 mol HClO；而 1 mol HClO 分解又生成 1 mol HCl。
总结果：Cl2 + H2O → 2HCl + ½O2↑（即 2Cl2 + 2H2O = 4HCl + O2↑），H+ 浓度增大，pH 变小。

五、次氯酸 (HClO) 的性质

① 弱酸性

HClO ⇌ H+ + ClO−

酸性很弱，比碳酸还弱：H2CO3 > HClO > HCO3−。
故：NaClO + CO2 + H2O = NaHCO3 + HClO（产物是 NaHCO3，不是 Na2CO3）。

② 强氧化性（漂白、杀菌）

HClO 能把有色物质氧化为无色物质，属于永久性、不可逆漂白；还能使蛋白质变性，用于杀菌消毒。

③ 不稳定性

2HClO 光照 2HCl + O2↑

见光易分解，故氯水、漂白粉都要避光密封保存。

④ 三种漂白原理大比拼

类型原理是否可逆
HClO / Na2O2 / O3氧化有色物质不可逆（永久）
SO2与色素化合生成不稳定无色物可逆（加热复色）
活性炭物理吸附物理变化

六、第二册 · 闯关测验

1. 新制氯水中不存在的微粒是：
答案 D。HCl 是强电解质，在水中完全电离为 H+ 和 Cl−，不存在 HCl 分子。新制氯水含三分子四离子：Cl2、H2O、HClO 与 H+、Cl−、ClO−、OH−。
2. 向新制氯水中滴入紫色石蕊试液，现象是：
答案 B。H+ 使之变红（酸性），随后 HClO 的强氧化性将其漂白褪色。
3. 下列能证明新制氯水中含有 Cl− 的实验是：
答案 C。Ag+ + Cl− = AgCl↓（白色，不溶于稀硝酸）。A 证明 H+，B 证明 HClO，D 证明 Cl2。
4. 关于久置氯水，说法正确的是：
答案 A。2HClO 光照分解，平衡右移，Cl2、HClO 耗尽，最终成稀盐酸，酸性增强、漂白性消失。
5. 干燥的氯气不能使有色布条褪色，湿氯气可以。说明：
答案 B。这是教材经典对照实验，证明漂白性来自 HClO 而非 Cl2。同理，液氯无漂白性。

第三册 · 氯气的实验室制法

一、气体制备装置的四大模块与选择依据

模块选择依据常见形式
① 发生装置反应物的状态 + 反应条件（是否加热）固固加热 / 固液不加热 / 固(液)液加热
② 净化装置杂质气体的性质（能否被某试剂吸收而不损失目标气体）洗气瓶（长进短出）、干燥管 / U 形管
③ 收集装置溶解性（能否与水反应）+ 密度（相对空气 29）+ 是否与空气成分反应排水法 / 向上排空气 / 向下排空气
④ 尾气处理气体的毒性与化学性质（酸碱性、可燃性）溶液吸收（NaOH 等）、点燃（CO）、气球收集
💡 口诀：「发生看状态与条件，净化看杂质，收集看溶解与密度，尾气看毒性。」

二、发生装置的三种基本类型

试管口略向下倾斜
适用于：O2（KMnO4/KClO3）、NH3
分液漏斗（控制速率）
适用于：H2、CO2、H2S、SO2、C2H2
需石棉网、温度计（控温）
适用于：Cl2、HCl、SO2(浓H2SO4+Cu)、C2H4
实验室制 Cl2：MnO2 + 4HCl(浓) △ MnCl2 + Cl2↑ + 2H2O
KMnO4 法（不需加热）：2KMnO4 + 16HCl(浓) = 2KCl + 2MnCl2 + 5Cl2↑ + 8H2O
其他：KClO3 + 6HCl(浓) = KCl + 3Cl2↑ + 3H2O；Ca(ClO)2 + 4HCl(浓) = CaCl2 + 2Cl2↑ + 2H2O
⚠ 三个易错点：
① 必须用浓盐酸，稀盐酸还原性弱、MnO2 氧化不了；
② 随反应进行盐酸变稀，反应自行停止，故盐酸须过量；
③ 1 mol MnO2 最多氧化 2 mol HCl 生成 Cl2，另 2 mol HCl 起酸性作用成盐。

五、动手搭一套"制氯装置"

目标：用 MnO2 + 浓盐酸制纯净干燥的 Cl2，并完成收集与尾气处理。请为五个位置选择正确装置：

位置 1 · 发生装置
✔ 反应物是固体 + 液体，条件需加热 → 选"固液加热型"：圆底烧瓶、分液漏斗（盛浓盐酸）、酒精灯 + 石棉网。
位置 2 · 除去 HCl 气体
✔ 浓盐酸挥发产生 HCl 杂质。用饱和食盐水：HCl 极易溶被吸收，而 Cl− 抑制 Cl2 溶解（减少损失）。
✘ NaHCO3 会与 HCl 反应产生新杂质 CO2，也会吸收 Cl2；✘ NaOH 会把目标气体 Cl2 一起吸收掉。
位置 3 · 干燥（除水蒸气）
✔ 浓硫酸有吸水性且不与 Cl2 反应。
✘ 碱石灰（NaOH + CaO）是碱性干燥剂，会吸收 Cl2：Cl2 + 2NaOH = NaCl + NaClO + H2O；✘ 无水 CuSO4 吸水能力弱，一般只作检验水的试剂。
顺序提醒：先除 HCl（饱和食盐水）后干燥（浓硫酸），颠倒则除杂后又带入水蒸气。
位置 4 · 收集装置
✔ Cl2 密度大于空气 → 向上排空气（长导管伸入瓶底，口部放浸 NaOH 的棉花团或用湿润淀粉-KI 试纸验满，试纸变蓝即满）。
✘ 排水法会因 Cl2 溶于水而损失；✘ 向下排空气法方向完全反了。
位置 5 · 尾气吸收
✔ Cl2 有毒，必须用NaOH 浓溶液吸收：Cl2 + 2NaOH = NaCl + NaClO + H2O。
✘ 水吸收不完全；✘ 澄清石灰水中 Ca(OH)2 浓度太小，吸收不彻底。
装置完成度：0 / 5

六、Cl−（氯离子）的检验

标准操作

取少量待测液
→
加稀 HNO3 酸化
→
滴加 AgNO3 溶液
→
白色沉淀 → 含 Cl−
Ag+ + Cl− = AgCl↓（白色，不溶于稀硝酸）
⚠ 为什么要先加稀硝酸酸化？
排除 CO32−、SO32−、PO43−、SO42−、OH− 等的干扰 —— 它们与 Ag+ 生成的沉淀（Ag2CO3、Ag2SO3、Ag3PO4、AgOH 等）都会溶于稀硝酸，而 AgCl 不溶。
⚠ 不能用盐酸酸化（会引入 Cl−），也不能用硫酸（Ag2SO4 微溶，可能干扰）。
干扰离子示例
CO32−：Ag2CO3↓ 白 → 溶于稀 HNO3 并放气泡
Br−：AgBr↓ 淡黄色，不溶于稀 HNO3
I−：AgI↓ 黄色，不溶于稀 HNO3
延伸：卤化银的颜色与用途
AgCl（白）、AgBr（淡黄）、AgI（黄）
三者均不溶于稀硝酸，且见光易分解（2AgBr 光照 2Ag + Br2）→ 用于照相底片、变色眼镜。

七、第三册 · 闯关测验

1. 实验室用 MnO2 和浓盐酸制 Cl2，发生装置应选择：
答案 B。MnO2(固) + 浓盐酸(液)，需加热 → 固液加热型。
2. 制得的 Cl2 中混有 HCl 和水蒸气，除杂的正确顺序与试剂是：
答案 C。先除 HCl（饱和食盐水，抑制 Cl2 溶解），后干燥（浓硫酸）。顺序不能颠倒，否则又带出水蒸气。NaOH/NaHCO3 会消耗 Cl2。
3. 检验氯气是否收集满，最常用的方法是：
答案 D。Cl2 + 2KI = 2KCl + I2，I2 遇淀粉变蓝。（也可用湿润蓝色石蕊试纸先变红后褪色。）
4. 检验某溶液中是否含 Cl−，正确的操作是：
答案 B。稀硝酸排除 CO32−、SO32− 等干扰。C 错：加盐酸会引入 Cl−，无论原溶液有无 Cl− 都产生沉淀。
5. 下列气体中，只能用排水法收集的是：
答案 A。NO 与空气中 O2 反应（2NO + O2 = 2NO2）→ 不能用排空气法；NO 难溶于水 → 用排水法。NH3 只能用向下排空气法。
