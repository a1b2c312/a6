为什么非要这么大？

核心概念

阿伏加德罗常数 N_A

N_A ≈ 6.02×10²³ mol⁻¹
定义基准：1 mol 粒子集合体所含的粒子数，与 0.012 kg ¹²C 中所含的碳原子数相同。
常取近似值 6.02×10²³ mol⁻¹ 用于计算。
注意 N_A 有单位 mol⁻¹，它不是纯数字；而 6.02×10²³ 只是它的近似数值。
点击辨析三个易混点
N 表示粒子数（个），无单位量纲
N_A 是常数，单位 mol⁻¹
n 是物质的量，单位 mol
三者关系：N = n · N_A
6.02×10²³ 是近似值，不是精确定义
点亮的每一条都是判断题的高频考法。

1. 下列关于物质的量的说法正确的是（　）

物质的量衡量粒子集合体的多少，单位是摩尔 mol。
2. 1 mol H₂SO₄ 中含 H 原子（　）
A．1 molB．2 molC．4 molD．8 mol
每个 H₂SO₄ 含 2 个 H 原子，故 1 mol 含 2 mol H 原子。
3. 3.01×10²³ 个 O₂ 分子的物质的量是（　）
A．0.5 molB．1 molC．2 molD．6.02 mol
n = 3.01×10²³ / 6.02×10²³ = 0.5 mol。
4. 下列表述规范的是（　）
A．1 mol 氧B．1 mol 大米C．1 mol NaClD．1 mol 物质
必须用化学式指明微观粒子；NaCl 指明的是离子化合物中的化学式单元。

归纳

这节课，我们学会了什么

1.　物质的量 n 是七个基本物理量之一，单位摩尔 mol，衡量微粒的「堆数」。
2.　1 mol 含约 6.02×10²³ 个微粒；阿伏加德罗常数 N_A ≈ 6.02×10²³ mol⁻¹，有单位。
3.　用 mol 必须写明粒子种类，且只用于微观粒子。
4.　n = N / N_A：见粒子数除以 N_A，见 n 乘 N_A；拆粒子按化学式下标放大。
